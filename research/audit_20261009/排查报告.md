已取消消息面模块，本轮没有接入新闻源、生成消息评分或调整股票与板块交易条件。排查覆盖实际运行入口、行情和日线刷新、缓存与历史读写、收盘发布、模型口径、板块目录、筛选、详情、导出和后台状态。下面区分已复现的问题、主动加固和仍存在的限制，不把测试通过解释成“项目绝无漏洞”。

| 问题 | 影响 | 修复与证据 |

| 页面生成失败仍返回成功 | 用户和自动任务误以为更新完成 | 页面或日报发布失败返回非零状态；故障注入测试复现了旧返回0、修复后返回1 |

| 本地离线重建可能改变日期却沿用旧派生榜单 | 新日线与旧收盘榜混用 | 跨完成日重建拒绝发布；同日重建重新生成收盘主榜 |

| 后台数据版本较旧仍可能显示已同步，连接中断无提示 | 用户误读页面与后台一致性 | 任意版本差异提示核验，连接失败明确标识；旧后台不能触发页面降级重载 |

## 安全与数据保护加固

- 数据嵌入页面脚本时转义 HTML 边界，特殊字符串不能提前结束脚本；解码后的数据原值保持一致。恶意边界形式的无害标记测试通过。本轮没有发现实际攻击事件。
- 本地服务核对 Host 与端口，刷新请求核对 Origin；外部来源及 cross-site 请求被拒绝，不触发采集。真实 HTTP 测试同时确认正常本地请求可用。
- 初始化错误文本转义后显示，避免错误内容被解析成页面标签。
- 资金流及历史资金补采继续保持停用，兼容旧字段不作为模型依据。

## 保持不变的规则与尚存限制

- 股票及板块的筛选阈值、均线趋势条件、价格评分权重、ATR算法、威科夫量价确认条件均未在本轮调整。修改集中在取数、版本隔离、读写、发布和验收。
- 五分钟刷新节奏与成员七日更新保持不变。过时的数据不改写源时间，正式日线不能用盘中报价冒充。不同模型的旧研究资料、资金库与备份不进入现行计算。
- **性能负担仍存在：** 排查前快照约102.5 MB，看板约105.6 MB；重建后的看板约104.7 MB。个股历史路径、题材关系和板块成员占较大体积，部分内容用于详情与完整导出。当前完整采集及发布约5分45秒，不能保证每轮都在5分钟内完成。未为缩小页面而删减判断依据，也未在本轮改造成按需加载；这个性能问题仍需独立处理。
- **免费行情源仍可能延迟或缺失。** 本次腾讯日线主机曾返回HTTP501，备用主机完成采集；11只标的没有可用日线。系统保留来源时间与缺口并避免生成无证据判断，不能承诺外部数据永不受限。
- 中文搜索通过程序填入中文验证，真实 Windows 输入法候选窗口仍取决于系统输入法与浏览器；本轮没有冒充完成系统级输入法人工验收。
- 09:15、11:30、13:00、15:05等边界的逻辑已覆盖测试，但本轮实际核验发生在盘后，不等于逐个时间点都完成实盘现场复测。
- 一次完整性排查及测试能证明列出的修复与当前可见流程，不能证明策略有收益优势，也不能证明所有外部异常组合均已覆盖。
