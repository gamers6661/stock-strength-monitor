## 数据口径与公式

成员取已有 member_codes 去重，关联同一主板股票池、本轮报价、stocks 和 coverage_catalog。数据缺失、日线不足和过期报价保留在应统计分母；明确排除对象逐代码记录原因和数量。未评分但有效报价可参加纯价格统计，不能补成趋势或突破。日线日期须等于 strength_model.asof，趋势资格必须可核验；当前事件另须价格口径有效、形态为本轮、无严重风险和不可交易限制。缺失值留 null。

| 指标 | 公式／口径 |
|---|---|
| R5 / E5 | 日线有效 ret5 等权均值 / 减全体有效主板5日等权收益 |
| P5 / T | ret5>0 比例 / 已核验趋势在线比例 |
| R0 / E0 | 当前有效报价涨跌幅等权均值 / 减同批全体有效主板当日等权收益 |
| U0 / A0 | 当日涨幅>0比例 / 当日涨幅≥3%数量 |
| B0 | 当前有效事件的不同股票数，仅指定五种 live_attack_event |
| 中位数 | 日线有效 ret5、有效当日涨跌幅分别计算 |
| 剔除领先成员 | 6—9只剔除最高1只，≥10只剔除最高3只；剩余等权及减同周期市场基准 |

全部计算和资格判断使用未四舍五入原值。有效成员至少6只、对应覆盖至少80%；6—9只标小样本。主板基准每个代码只算一次，基准覆盖不足80%时相对资格待核验；不平均题材收益，也不将剔除结果描述为官方指数权重贡献。日线、报价、事件有效集合和源时间在输出中分开保存。

| 资格 | 固定条件 |
|---|---|
| 日线持续强势 | 有效≥6、覆盖≥80%、R5≥3%、E5≥2个百分点、P5≥60%、T≥max(25%,市场T+10个百分点)、剔除后R5>0且E5>0 |
| 当前持续强势 | 日线资格成立；当前有效≥6、覆盖≥80%、R0>0、E0>0、U0≥50%、剔除后R0>0且E0>0 |
| 新启动当轮 | 当前有效≥6、覆盖≥80%、R0≥1%、E0≥1个百分点、U0≥60%、A0≥3（6—9只要求≥2）、剔除后R0>0且E0>0 |
| 回踩再启动当轮 | 背景成立、当前同名指数ready、现价≥滚动MA5/MA10、未转弱；当前有效≥6、覆盖≥80%、R0>0、E0>0、U0≥55%、剔除后R0>0且E0>0、B0≥2 |

回踩背景要求同名指数、原状态机同趋势段回踩记录，以及回踩前20个完成交易日内的真实 daily_mainline 记录或当时及以前完整6日窗口算出的指数5日涨幅≥5%。后者只标“指数历史进攻背景”。缺失或不足保持待核验，不用当前成员名单回填。趋势段结束或转弱清除；同段修复后仍保留背景；R5不设3%门槛。
