# 首页趋势观察优化验收

运行模型：**强股整理观察2**。本轮将首页原近线观察改为“此前进攻 → 回踩或横盘整理 → 逐轮转强确认”。原MA5/10/20近线名单保留在同一板块的可展开对照中。

## 已实现的行为

- 进攻依据发生在整理开始之前：此前真实日线A记录，或上涨阶段连续5个交易日涨幅达到8%。不以当前A/B/C档位排除整理股。
- 完成日MA10高于MA20、MA20上行、收盘守住MA10；整理期间各完成日收盘也须守住各自MA10。
- 当前严格趋势在线和“近期趋势整理，待恢复排列”明确区分；后者最近5个完成日必须有过严格趋势在线。
- 回踩与横盘均识别。收盘价小幅抬高、真实波幅已收窄的紧凑横盘也可入选，不机械要求现价距离均线1%以内。
- 完成日量能判断缩量；量能缺失标未知，不补零、不从盘中累计成交量推断整日缩量。
- 平台上沿取完成日整理区间最高价，盘中不随当日高点移动。价格比较沿用统一复权、日期、来源核验入口。
- 连续确认使用当天完整真实采样。重复时间不增加次数，缺失及超过15个交易分钟的间隔打断确认，午休不算交易间隔。迟到数据不覆盖较新判断。
- 有效新报价失守MA10、出现严重转弱或成交受限，退出健康整理观察；数据缺失或口径未知时保留最近有效记录，并标留档。
- 首页及个股详情展示上涨窗口、整理开始日、整理天数、回撤、量能、真实波幅、平台上沿及确认次数。CSV追加16个整理字段。

## 状态及排序

优先处理有风险提示的排序降级，再依次比较：平台突破观察、整理转强观察、平台突破待确认、回踩企稳观察、强股整理。同组比较整理质量、此前进攻幅度，资金只作最后辅助比较。留档记录排在当前有效记录之后。

| 状态 | 条件 |
|---|---|
| 平台突破观察 | 连续至少2次有效采样高于固定平台上沿、守住MA10和开盘价、跑赢市场且未触发严重风险 |
| 整理转强观察 | 连续至少2次有效采样高于前一完成日最高价，其他方向及风险条件同上 |
| 平台突破待确认 | 仅本轮达到平台突破条件，尚未取得连续确认 |
| 回踩企稳观察 | 连续至少2次守住MA10，且本轮价格较前轮回升；属于采样观察，不声称已经确认分钟级底部 |
| 强股整理 | 前史及完成日整理资格通过，现价守住MA10，但没有上述转强确认 |

“平台突破”在整理初期可仅有1—2个完成日，页面明确显示天数，不把短期回升包装成成熟平台。盘中信号仍须收盘验证。

## 公开研究初值

| 项目 | 当前数值或口径 |
|---|---|
| 历史窗口 | 40个完整交易日；日期、OHLC及来源/复权整窗核验 |
| 整理锚点 | 最近12日内的收盘峰值；紧凑上移横盘使用其上涨窗口末日 |
| 进攻窗口 | 锚点及此前4日的5日涨幅窗口，全部结束于整理之前 |
| 优先整理时长 | 3—8日；1—2日及9—12日降低质量优先级 |
| 回踩 | 优先0.5—2 ATR，超过2.5 ATR退出；ATR不足不形成新判断 |
| 横盘区间 | 不超过2.5 ATR；上移横盘额外要求累计上移≤0.5 ATR、整理真实波幅≤此前上涨期的0.85倍 |
| 近线标签 | MA5/MA10上方0—0.8 ATR；用于位置说明，不是横盘的必要条件 |
| 缩量加分 | 整理期平均成交量/选定上涨5日平均成交量≤0.8 |
| 波动收窄加分 | 最近至多3个整理日平均真实波幅/锚点及前两日平均真实波幅≤0.85 |
| 放量下跌排除 | 整理日成交量超过上涨期平均量1.3倍，且相对前一完成日收盘下跌≥0.5 ATR |
| 连续低点下移排除 | 最近3个整理日低点和收盘价均连续下移 |
| 整理质量排序分 | 时长30、缩量25、波幅收窄25、适中回踩20；不改变原日线进攻分 |
| 位置过热 | 仍使用原有MA5距离严格超过3.5 ATR；其他跌幅/结构风险保留 |

这些是可复核的初始规则，不是已证明的最优参数。资金缺失不使观察股失去价格资格，也不证明主力意图。
