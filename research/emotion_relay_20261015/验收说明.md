# 主板龙头接力与合并方向页验收

交付日期：2026-10-15。按《均线趋势与龙头接力优化方案》第七节及第二轮实施范围完成。本轮没有调整均线趋势准入、阶段转换、支撑和退出规则。

## 页面与判断变化

- 原“板块”“题材”合为“板块／题材”，默认全部方向，可切换行业、题材，保留同花顺名称、确认成员、完整成员排名及官方指数图表。
- 新增“情绪”页：前一完成日高度与梯队、当前在板梯队、分板位晋级、昨日连板股反馈、断板反馈，以及高标／同身位竞争／同题材接续观察。
- 情绪按真实涨停事件与接力角色判断，和MA资格独立。个股完整成员排名的接力列改用角色、板位、在板状态、反馈和成交额，保留全部成员。原综合参考顺序与趋势力度顺序保留，页面明确两种排序口径。
- 新标签支持悬浮解释；中文搜索在输入法组合期间保持输入框；涨幅红色、跌幅绿色。列表、详情、导出使用同一UI版本。
- 午休保留实际源时点；跨13:00或报价有效期后，当前接力候选不再继续作为有效事件显示。官方指数的保留上午快照另标“原时点参考”，没有改成11:30新报价。

## 固定V1规则

| 项目 | 本轮标准 |
| --- | --- |
| 统计范围 | 现有沪深主板普通10%制度股票池，非全市场；特殊制度不混比 |
| 历史封板 | 涨停池完整性与请求日交叉核验；原价收盘、最高价、池中价格和前收×1.10按分四舍五入价格一致 |
| 连板链 | 未封板中断；缺失／特殊制度日为未知，不能当作未涨停或精确首板；不直接使用供应商连板数字 |
| 当日在板 | 有效原价行情、前收语义、真实成交、OHLC及实际涨停价核验；盘中待收盘与正式收盘分别显示 |
| 新股制度 | 尚无至少五个此前完成成交日，或名称为特殊上市期标记时，不假定普通10%限制 |
| 空间高标／题材领先 | 已核验至少2板，以可确认高度比较；题材领先还要求排除本股后的同行覆盖达标，不提前宣布唯一龙头 |
| 同身位竞争 | 昨日精确完成板位相同且至少2板的股票作参照；不凭单个快照宣布胜出 |
| 同题材接续 | 已有至少3个完成连板的核心，核心最新仍在板；本股主动封首／二板，至少低2个板位；近5日非旧高标 |
| 接续的题材约束 | 排除本股后至少5个有效同行，覆盖≥80%，至少2只同行在板，同行在板密度≥有效主板样本的1.5倍，主板有效覆盖≥80% |
| 同题材扩散 | 同行覆盖达标、至少2只同行在板、上涨占比≥60%；只是同步证据，不推断因果带动 |
| 接力环境 | 至少5个有效昨日封板样本、覆盖≥80%；晋级≥50%且反馈中位数为正为维持，晋级<25%且中位反馈≤-3%为负反馈增加，其余分化 |
| 风险／采样 | 涨幅≤-5%单列负反馈；一字价格区间提示成交受限；开板／回封仅称“采样观察到”，不虚构全日次数或首封时间 |

以上是固定的首版观察规则，尚未经过前向收益验证。没有输出连板成功概率、封单强度或“躲异动”动机结论。资金因子继续停用。
