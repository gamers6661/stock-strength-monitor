# 板块趋势筛选第二轮

强势推进增加 MA5 > MA10。行业与概念指数使用同一套分阶段规则；个股规则、评分、板块成员资格、原始成员排名及300秒刷新配置保持原样。

## 规则

| 状态 | 完成日线条件 | 处理 |
|---|---|---|
| 沿5日线启动 | 连续3日收盘守各自MA5、MA5逐日上升，末日收盘高于首日 | 可在MA20下方入观察 |
| 强势推进 | 收盘≥MA5、MA10；MA5>MA10；两线均较前日上升 | 入重点观察，不要求MA10>MA20 |
| 趋势回踩 | 本段已有强势背景，回落至MA5下方或测试MA10 | 保留背景，短暂MA5下行不直接判弱 |
| 浅破待收复 | 收盘低于MA10且缺口≤固定0.3ATR | 自首次失守起缓冲2个交易日 |
| 深回踩警戒 | 缺口>0.3ATR，尚未达到失效条件 | 警戒标签，继续观察修复 |
| 10日支撑失效 | 缺口>1ATR，或第三个交易日仍失守 | 移出重点；已建立MA20支撑则转20日支撑观察，否则结束本段 |
| 回踩修复 | 收盘收回MA10 | 连续2日守住或重新满足强势推进，才清除失守计时和固定ATR |
| 20日支撑建立 | 本段观察连续2日收盘≥MA20 | 此后收盘跌破MA20即判弱退出，优先于强势推进信号 |
| 早期启动失败 | 尚未形成强势、未建立MA20支撑；连续2日收盘<MA5，或单日低于MA5超过启动时0.5ATR | 结束本段，后续重新满足新条件才能入观察 |

回踩开始时固定前一完成日的ATR20，公式为20个含跳空真实波幅TR的简单平均。首次跌破MA10的日期不因单日收回而清零。日内下探MA10超过固定0.5ATR后收回标记“深探收回”，不直接判弱。MA20日内失守而收盘守住，不构成完成日线退出。

退出当日不重用旧启动序列立即入选；新条件从后续交易日开始。历史逐日重放只使用当时及以前数据；中间缺口切断旧背景，最新22日有缺口则待核验。完整历史日历保留，不因盘中调用方的滚动窗口截断尚未结束的回踩起点。

数值是本次批准的初始规则参数。历史重放验证状态衔接，未据此调优参数或声称收益表现。

## 页面

默认“重点观察”。提供强势推进、沿5日线启动、回踩观察、20日支撑、已转弱、成员扩散、全部入口。已转弱只在复核入口展示，不进入重点与支撑观察。成员扩散独立展示，不改变指数是否转弱的判断。

状态、恢复阶段/20日支撑、失守/修复计时以标签呈现，点击查看依据。当前ATR距离与回踩固定ATR明确区分。详情显示本段起点和首次失守日期，完整公式放入折叠说明。
