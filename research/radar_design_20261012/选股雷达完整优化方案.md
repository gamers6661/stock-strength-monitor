**选股雷达完整优化方案 V1｜2026-10-12｜方向负责人建议与操作员实施规格**

本文件是设计与验收规格。本轮只创建方案文档，没有修改运行中的筛选、评分、采集或页面。以下“应当”“实施”均指后续操作员工作，不代表已完成。

这是当前数据与项目约束下的首选实施方案，目标是提高机会发现和解释质量。它尚未证明收益、胜率或回撤优于现有模型。“最优参数”须通过冻结规则后的前向对照判断。

**1. 目标与现状依据**

目标是发现实际上涨、有结构依据的突破启动、强势整理后再启动和持续进攻。日线资格、当日机会、板块环境、风险及成交限制各自判断，不能用一个分数相互抵消。

当前实现已核对：

| 现有机制 | 本版处理 |
| --- | --- |
| 股票池为沪深主板，排除现有ST、退、PT等名称条件 | 沿用实际股票池，不扩创业板、科创板和北交所 |
| 进攻分由5/10/20日推进按50%/30%/20%组成；周期内60%绝对推进、40%同口径分位 | 保留原公式、满分涨幅和权重 |
| A/B/C由完成日趋势、进攻分及实际涨幅确定 | 保留为完成日背景，标明日期 |
| 盘中价格进攻、盘中转强、强股整理、量价结构与板块机会已存在 | 复用其核验结果和可用结构，不另造一套行情口径 |
| 雷达仍以watch_candidate日线趋势池为入口 | 新增全部合格样本可进入的机会层，不能先被日线池截断 |
| 正常扫描300秒；资金流已停用 | 保持采集频率、并发与资金停用状态 |
| 当前RISK_GATE.min_trading_days为25，表示历史根数门槛 | 不使用配置中的旧120日注释推断现行规则；25根不等同于已上市25个交易日 |

实际代码入口：radar.py、attack_model.py、intraday.py、trend_consolidation.py、board_opportunity.py、config.py、scoring.py。策略名称中的旧版本文字及历史研究参数不能当成当前因子。

**2. 一张机会表，三类机会，两个辅助视图**

主表称“当前机会”，分类为“强势再启动”“突破启动”“持续进攻”。同一股票只占一行，可以保存多个成立的事件标签。仅为避免重名，主要标签优先级为强势再启动、突破启动、持续进攻；该顺序不代表预期收益排序。

辅助视图为“预警与跟踪”“日线背景”。前者容纳早期预警、待确认、突破回落、修复、数据暂停及已结束事件；后者保留A/B/C。有效机会为零时显示零，不降低门槛、补名额或自动混入背景股。

主表的强度与观察限制分开：确认成立但已知成交受限的股票放在主表的独立折叠区，仍计入进攻事实总数，不混入默认可观察列表。其报价不被视为可成交承诺。

**3. 数据准入与统一计算口径**

机会计算读取stocks与coverage_catalog的按代码合并结果，先去重。只有通过所需历史窗口、当日报价及价格尺度核验的样本可产生信号；coverage_catalog中不能判断的股票继续可查询。

| 项目 | 强制要求 |
| --- | --- |
| 正常触发时段 | 9:30—11:30、13:00—14:57的连续竞价；14:57后不新增盘中采样确认 |
| 报价 | 当日、来源时间有效、价格/OHLC合法、有成交；沿用现有600秒时效、300秒批次偏差、90秒未来容差 |
| 历史 | 核心评分至少25根应有完成日线，日期对齐；强势整理背景需要现有40根窗口 |
| 价格尺度 | 来源、复权方式、完成日日期、昨收和完整窗口均已核验；使用共用price_contexts转换副本 |
| 风险状态 | 严重转弱必须明确为否；未知不得被当成通过 |
| 无成交/恢复成交 | no_trade、trade_recovered_wait_daily不产生当前机会 |
| 缺失 | 数值为null，状态为待核验，不记0分，不将缺失当作转弱或条件未满足 |

超过原时效的记录只能展示最近有效判断与真实时间，不计入当轮确认。时间倒退与重复源报价不能形成新确认。源数据原始K线、日线评分及正式留档保持原样。

统一变量如下，涨幅单位均为百分数，差值单位为百分点：

| 变量 | 定义 |
| --- | --- |
| P | 最新有效实际报价 |
| R0 | 同一报价的当日涨幅；昨收语义核验通过 |
| M0 | 当前沪深主板股票池有效有成交报价的等权当日涨幅 |
| E0 | R0减M0，不能标成收益率比例或官方指数收益 |
| U0 | M0样本中上涨股票数除以有效股票数，平盘计入分母 |
| MA5*/MA10*/MA20* | 用P替代今日暂态收盘，加前4/9/19个完成日同尺度收盘；不把今日累加为额外完整交易日 |
| A | 最近完成日ATR20-SMA，使用21根K线产生20个含跳空真实波幅；只在已核验尺度副本上同比例转换 |
| H5 | 首次预警前最近5个完成交易日的最高价最大值，不含当日最高价 |
| Hc | 强势整理背景保存的平台高点，不能随当前价格上移 |
| b | 突破缓冲max(0.01元,0.1×A)，0.1ATR沿用现有量价结构观察初值；这是研究初值，不保证最佳 |

M0样本不能只取A股、趋势股或待选股票。覆盖分母使用当日固定主板池，减去通过明确当日成交状态确认的无成交样本；报价缺失者仍在分母，不能以“可能停牌”删掉。有效报价覆盖须至少80%，复用板块机会覆盖下限；不足则M0/E0及环境为待核验，停止正式新入池，但保留个股价格预警。显示有效数、应覆盖数、覆盖率和报价时段。基准成立也不代表缺失样本没有选择偏差。

用于M0的报价须在当轮同一有效时段和批次容差内。个股与板块参考日期/时段不一致时，不能贴当轮共振标签。所有门槛比较使用未四舍五入值，页面显示值仅作展示。

**4. 三类机会的正式条件**

下列条件必须同时成立，且通过第3项准入。第一次满足正式门槛即展示“待采样确认”，满足第5项确认规则后进入当前机会。

| 类别 | 历史背景 | 正式价格与方向条件 | 不要求的条件 |
| --- | --- | --- | --- |
| 强势再启动 | 突破前已存在现有模块认可的合格强势整理背景；平台及进攻前史已保存 | P>Hc+b；R0≥2%；E0≥1个百分点；P≥开盘价、MA5*、MA10* | 今日暂态A、最近5日再涨到A门槛、当前仍在贴线整理名单 |
| 突破启动 | 25根核心历史可核验，H5与ATR可核验；本轮事件仍在首次观察的3个交易日窗口 | P>H5+b；R0≥3%；E0≥2个百分点；P≥开盘价、MA10*、MA20* | 昨日非A、昨日完整多头排列、当前暂态A |
| 持续进攻 | 最近完成日为A档 | R0≥2%；E0≥1个百分点；P≥开盘价、MA5*、MA10* | 必须创新高、必须属于强板块 |

突破启动先设低一级价格预警：同一H5突破与均线/开盘价条件成立、R0≥2%、E0≥1个百分点，展示“突破预警”，不冒充正式门槛成立。基准不可核验时，仅显示“价格越界，超额待核验”。

强势再启动沿用现有背景：整理前具备实际进攻与原趋势资格，5日推进≥15%或10日推进≥20%；整理2—12个完成日、40根历史窗口及平台宽度/回撤等条件均由现有daily_setup及跟踪记录判定。不复制公式，不仅凭近期最高价下降自称强势整理。3—8日、缩量、收敛等质量信息沿用现有解释，不另加进攻分。

平台读取突破前已验证记录，包括后来进入initial/completed的同一整理事件；当前eligible=False若仅表示已经突破，不能抹掉已验证背景。若背景失效、尺度不可比或前史未知，不能继续用旧平台。

不满足严格强势整理前史的普通平台突破，可通过“突破启动”观察，但不能改名“强势再启动”。修复、反包、MA回踩反弹未超过平台时，继续使用现有观察标签，留在辅助视图。回踩反弹不能仅因涨幅达到2%就冒充平台突破。

持续进攻股也可以发生新的突破事件。昨日A不能阻止它进入突破启动；主要标签切换不删除其A档背景。

**5. 事件、确认、维持与失效**

三类机会首次正式入池均需两次不同来源时间的有效报价满足同一正式门槛，跨度至少300秒、相邻间隔不超过600秒，且在同一个上午/下午连续竞价时段。不能用两个快照生成时间代替两次源报价时间。

报价覆盖不足、价格尺度未知、严重风险、间隔超限、不同交易日或不同半日会中断采样连续性。遇到缺失记录，原事件变为“判断暂停”，新报价恢复后重新确认；不伪造已经失效，也不沿用旧确认冒充当前确认。

| 状态 | 进入原因 | 展示/后续 |
| --- | --- | --- |
| 预警 | 突破启动低一级条件或价格越界 | 辅助视图，立即可见，不承诺完整资格 |
| 待采样确认 | 单次满足正式条件 | 显示首次观察时刻、待确认原因 |
| 当前已确认 | 两次满足正式条件 | 主表；明示只是两次采样成立，不是连续站稳证明 |
| 判断暂停 | 数据/时段不能支持当轮结论 | 保留最后有效价格及时间，退出当轮默认机会，恢复后重新确认 |
| 进攻暂停/突破回落 | 有效数据下不再满足维持条件 | 辅助跟踪，给出具体失守项 |
| 严重转弱 | 原严重风险或 required MA失守 | 立即退出当前机会，保留原事件与日线背景 |
| 收盘确认/收盘未确认 | 正式完成日线已经到库 | 依据同日正式条件与冻结平台复核；没到库先标待收盘核验 |

首次确认后的维持门槛适当放宽，以避免在2%或3%附近反复进出：R0>0、E0>0、P仍不低于开盘价及本类别required MA，严重转弱明确为否；突破类还须P>冻结H，不再强制保持b缓冲。实际跌回H及以下即标突破回落，不能等第二次报价才显示。正式条件不再满足但仍通过维持条件时，标“已确认，进攻减速”，不能展示成刚满足正式门槛。

维持规则只对已经确认的同日事件生效。次一交易日、午后首段重新取得正式采样确认；不凭昨日确认或午休缓存绕过今日门槛。反复进出不改写首次观察/首次确认时间，不追加重复独立事件；恢复后有last_reconfirmed_at。

突破类首次观察时冻结平台、背景日期、ATR、价格尺度指纹、规则版本和event_id。event_id应基于代码、类别、真实平台锚点/整理起点、规则与尺度身份；不能直接把每天变化的asof或snapshot generation当成事件身份。同一整理事件的setup_id即使随asof变化，也须映射回原锚点。

“突破启动”有效展示窗口为首次正式门槛被观察到的当天及随后两个交易日，按交易日历计数。超过窗口转“突破后跟踪”；若同时满足持续进攻条件，可主要展示持续进攻，保留原突破事件。不能每天重新冻结H5，把连续上涨重复标成新启动。只有原事件已经结束，且之后至少两个完成日收盘回到原平台H及以下，才允许基于此后完成日重新建立该类事件；规则/尺度变更重建须标新版本观察，不能声称经济意义上的再启动。

强势再启动也只在首次正式触发后三个交易日内作为当前“再启动事件”分类；之后保留跟踪和原平台，当前强度满足持续进攻时按持续进攻展示。新的再启动必须有新的合格完成日整理背景。

次日/午后的再确认不重新冻结平台，也不延长三日事件窗口。当日收盘确认只使用正式完成日K线和同日有效收市基准；需满足该类别正式条件，盘中曾成立不等于收盘成立。原盘中记录仍保留。

**6. 市场、板块、题材与位置风险**

市场环境复用M0、U0，作为注意力与风险提示，不动态降低/提高个股门槛。研究初值：M0≥0.5%且U0≥55%为偏强；M0≤-1%且U0≤35%为偏弱；其余为分化。分类改变须同半日两次有效基准采样，间隔与跨度沿用第5项；不足覆盖为未知。

偏弱时提示优先检查已确认再启动及真实同行共振，仍保留独立强股；偏强时提示扩散行情与普通跟随风险。每天名单多或少均不构成改参数理由。涨跌停、触板未封、昨日涨停反馈沿用现有情绪轴，第一版不加入进攻分、不新增情绪总分门槛。

板块关联使用同花顺确认成员与已有board_opportunity的当前确认状态，不读取昨日机会当作当前。行业和题材分别保留，多个重叠概念不累计加分。个股先独立合格，不能因为属于强板块就升档。

可展示两个事实：“所属板块当前入选”“剔除本股后的同行共同走强”。后者用该板块当前有效主板报价，剔除本股后至少5只、对已确认成员覆盖≥80%、上涨占比≥50%、同行涨幅中位数>M0；门槛复用现有板块样本/覆盖/广度原则，仅用于标签，不进入个股正式准入或排名。只满足前者就显示前者，不能直接写“板块共振已验证”。分类/成员/当前报价缺失时显示待核验，不能推断为独立进攻。同行同时上涨不是本股带动同行的证据。

默认排序不为板块加分；提供共振参考筛选。所属行业/题材的全部通过项目能在详情展开，不能事后只显示最强概念而隐藏其他关系。

| 风险/限制 | 处理 |
| --- | --- |
| 接近跌停、大幅下跌、明显冲高回落、required MA失守等原严重风险 | 即刻取消当前资格，保留事实与历史 |
| P距MA5*严格超过3.5 ATR | 显示位置偏热，不从进攻分扣分，也不因股价上涨自动删掉上涨事实 |
| 触板未封 | 显示分歧；沿用实际当前状态，不永久惩罚盘中曾触板的股票；不另改其他模块风险口径 |
| 一字涨停/既有明确成交限制 | 进攻成立时进入“观察受限”区；不假设按显示价可以买入 |
| 缺盘口/同时间量能序列 | 明示未完成成交/量能确认，不自动生成“资金抢筹”“放量突破” |
| 历史成交额 | 现有量×收盘价估算可作参考，标明估算；不伪装成真实成交额，不新增未经验证的硬流动性门槛 |

本系统的采样失效提示不是同日可执行止损。普通A股买入受交收前不得卖出约束，T+1及涨停报价可成交性必须在任何交易收益模拟中另行处理。

政策消息、业绩公告、监管、减持等事件只有来源和时间明确才可作为事实提示。当前没有完整可靠事件源时，不编造“无消息风险”或给新闻情绪打分；价格雷达对突发事件保留这一盲区。

**7. 排序、页面与查询**

当前已确认且没有已知成交限制的默认列表，按E0降序、现有live_attack_score降序、R0降序、代码升序排序。得分缺失排在有效分后，不冒充0；当前条件不需要该分数时，不能因没有A档就拒绝启动。待确认/预警与观察受限独立展示，不混入默认顺序。分类优先级只用于标签，不能把所有再启动无条件压在所有突破启动之前。

提供类别、共振参考、位置偏热/分歧等筛选。用户手选筛选保留；市场变化不擅自改用户筛选。无固定入选名额，分页或显示上限不改变总数和完整导出。

单行最少显示代码名称、主要机会类型、当前状态、报价时刻、R0、E0、现有盘中进攻分、日线档位与日期、板块参考、风险/观察限制、首次触发时间。详情展开冻结平台、当前距离、全部资格项实际值/门槛/未知原因与事件历史。每一未入选股票都可查询原因。

同一代码主表不重复；跨类别筛选允许展示同一股票不同标签，但总数按代码去重。页面列表、详情、CSV及事件留档绑定同一data_version/generation。采用页面现有布局与详情入口，不新增浮夸的总分仪表或只用于解释的独立数据库。

CSV维持已有列含义，仅追加必要新列；不把背景A替换成当前确认状态，不改旧历史导出的定义。

**8. 时段处理**

| 时段 | 行为 |
| --- | --- |
| 盘前/非交易日 | 最近完成日日线背景与历史事件参考，不新增当前机会 |
| 开盘竞价及9:25—9:30等待 | 独立竞价预警；不进入连续竞价正式采样确认 |
| 上午连续竞价 | 正常计算，等待同批覆盖成立；首条满足即显示待确认 |
| 11:30至13:00 | 使用现有上午收市缓存，冻结上午状态并标截至时刻；不增加确认计数 |
| 13:00之后 | 逐股真实午后报价与午后基准到齐后重评；上午缓存不得充当午后第二次报价 |
| 14:57—15:00 | 保留最后连续竞价判断，可根据有效报价提示撤销；不新增采样确认 |
| 收盘日线尚未入库 | 显示待收盘核验，不把15:00报价当正式日线 |
| 正式日线入库后 | 按已保存事件平台复核当天收盘条件，生成当天确认/未确认留档 |

**10. 工程与业务验收**

| 用例 | 必须得到的结果 |
| --- | --- |
| 完成日A，但今日下跌 | A背景仍在，当前机会不成立 |
| 完成日非A/趋势未排好，但有效突破H5且正式条件成立 | 不受日线watch_candidate拦截，两次确认后进入突破启动 |
| 完成日A，发生本轮首次有效突破 | 可进入突破启动，不被“昨日是A”排除 |
| 严格合格整理股，当前ret5偏低但突破冻结Hc | 可按再启动条件进入，不必重新达到当前A |
| 普通反弹、修复或MA回踩，没有平台突破 | 不能进入强势再启动 |
| 所属板块强，但个股正式条件不成立 | 板块不能救个股入池 |
| 个股强、可核验但没有同行共振 | 保留独立机会，不降分 |
| 板块分类/报价未知 | 显示板块待核验，不能叫独立进攻 |
| 重复报价/源时间倒退/仅刷新生成时间 | 确认次数不增加 |
| 午休重复刷新/上午样本加下午样本 | 午休不计数，跨半日不能拼确认 |
| 个股或M0覆盖未知/价格尺度不一致 | 停止新正式结论，缺失不记0，不自动转弱 |
| 门槛边缘回落，但已确认且满足维持条件 | 留池并标进攻减速，不虚报重新触发 |
| 跌回冻结平台或required MA失守 | 立即提示回落/失守；只保留历史背景与事件 |
| 突破后当日最高价上涨 | 原H/ATR/首次时间不改写 |
| 同一股票多类满足、多概念重叠 | 主表一行，总数去重，概念不累计加分 |
| 已确认且一字封板/已知成交限制 | 观察受限区；不假设成交 |
| 无符合条件股票 | 合法空池，不补名额 |
| 规则版本改变或服务重启 | 历史事件保留版本；重启不能新增长确认、修改首次时刻 |
| 页面与导出 | 同版本同代码同条件同排序；日期和标签含义一致 |

冻结规则单测、完整现有回归、check_dashboard.py、check_live_service.py及真实页面路径都需有结果。测试失败须分别说明新增故障、既有故障和外部环境问题，不能只展示通过子集。整轮新增计算耗时应在同一输入下测量，不能为了快静默删样本；若影响原五分钟周期，先定位重复计算/写入，不直接缩短或扩大采集。

工程验收通过仅证明实现正确，不证明投资效果。

**11. 效果验证与参数治理**

对照包含当前日线A机制、现有attack_watch_candidate、startup_candidate以及新方案三类信号，不能只挑功能少的旧雷达对比。使用相同股票池、行情来源、源时间、价格尺度和观察窗口。

每个事件固定记录代码、类别、rule_version、event_id、首次预警/正式触发/确认时刻及价格、当天M0/E0、冻结平台/ATR、背景日期、板块状态、风险和失效原因。原始记录不能被后续更好的标签反写。股票池和成员关系使用当时快照；不得用今天的成员或已知后续结果回填过去的共振，不能把完成日日线重算冒充真实盘中记录。

主要观察项目：首次触发和确认分别计算后续1/3/5个交易日相对同口径主板基准的收益分布，报告均值、中位数、正超额比例、信号后最大不利幅度与确认延迟；同时报告股票覆盖、重复事件及无法计算比例。板块共振与独立机会、三类机会、上午与下午、不同市场环境分别比较。

最大不利幅度只能使用信号后的有效采样或随后完成交易日OHLC。当日最低价可能在信号之前，不能直接拿来计算信号后回撤；五分钟采样只能报告采样所见不利幅度，不能宣称覆盖了真实路径。

列表可比相同前10/20只的排序结果，但这是研究对照，不是生产强制名额。全量符合条件名单同时保留。重复同股同事件只计一次；同股同次触发的多个类别标签在全体统计只算一次，各类别分组需披露重叠。按交易日汇总检查共同市场行情影响，不能把几百个同日高度相关信号当成几百次独立证据。

第一阶段前20个交易日检验数据、迟滞、漏选与误报；收益结论保持初步。至少积累60个交易日并检查三类事件及不同环境的覆盖，每类100个不同股票事件仅作为样本充足检查线，不等同于统计显著或收益最优；不足的分组明确报告不足，不能凑数证明有效。

参考报价后续收益与交易收益分开。需要交易收益对照时，必须另定明确入场/出场规则、T+1约束、不可成交处理及费用；不允许按信号前价格入场、假定涨停成交或当天止损。没有盘口和实际成交记录时，下一条报价仍只是参考报价，无法证明成交。

只做必要拆项：先保持原评分验证新增入口，再比较单次信号与二次确认，最后比较共振/独立组；不在同一批数据大规模扫描权重与阈值组合。若规则不能稳定改善相关目标，删除或降为解释，不因规则已经开发就保留。调整须新版本和新观察期，旧记录留在旧版本。

**12. 本版边界与可核查来源**

当前数据是主板价格监测，不覆盖完整A股、不具备完整盘口与实时同时间段量能。5分钟采样可能错过快速拉升，完成日MA与严格整理前史会漏掉部分早期或温和推进股票；H5突破仍可能失败，ATR缓冲与百分比门槛仍属研究初值。新增门槛多来自同一价格信息，不构成多份独立预测证据。

这一版选择以明确机会类型、即时预警、真实采样确认、独立风险和冻结事件记录解决这些问题，而非声称消除它们。

交易规则原文：[深交所2026年交易规则](https://docs.static.szse.cn/www/lawrules/rule/trade/current/W020260424690713155663.pdf)，包括交易时段、交收前不得卖出及竞价撮合原则；[上交所2026年交易规则发布页](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)，载明2026年7月6日起施行。

参数研究边界：[Stock portfolio design and backtest overfitting](https://www.davidhbailey.com/dhbpapers/stockfund.pdf)。该研究支持控制历史寻优与重视样本外验证，不证明本方案在A股有效。

检索记录：交易所域名检索“交易规则、当日买入、不得卖出、价格优先、时间优先”等，两组查询、一次批量检索并打开原文；豆包就主板雷达的迟滞、重复价格信息、样本外验证及成交假设审查一次，因BROWSER_CONNECT未取得内容，不作为依据。
