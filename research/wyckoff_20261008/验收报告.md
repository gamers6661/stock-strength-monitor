# ATR与量价结构结合：第一轮验收

本轮新增独立的“量价结构观察1”，实现固定整理平台、收盘价格突破、收盘量价确认、突破后的缩量回测及失败留档。原日线进攻分、盘中进攻分、主榜和原候选门槛不变。此轮完成的是规则接线与功能验证，尚未证明收益、胜率或优于原方案。

## 实施范围与数据时间

新增 `wyckoff_structure.py`；配置、扫描、服务、日报、看板和验证入口接入该观察模块。看板的强股整理卡片显示结构摘要，普通个股及覆盖目录详情显示原平台、固定ATR、量波收敛、当前限制与事件日期；个股CSV增加15列结构字段。

首次识别时冻结平台上下沿、完整20个真实波幅的ATR20、20个完成日成交量中位数及对应源价格窗口。平台随后的变化不会重写原平台。正式记录只使用已入库的同源日线，不使用快照里由当日报价拼出的K线；当日须在15:05以后且处于已收盘阶段才允许核验。缺日期、OHLC异常、来源/复权不明或历史价格发生不能确认的改写时保留事实并暂停新判断。

盘中价只与已核验的报价尺度比较，重复时间不增加持续次数，缺口打断采样；竞价、午休、过期报价仅作历史参考。已关闭周期或价格尺度待核验时不展示未经验证的当前突破价。首次部署从实际识别时间开始跟踪，不回填先前突破。

## 第一轮规则

| 环节 | 判断及边界 |
| --- | --- |
| 整理来源 | 使用现有强股整理资格，要求至少40个对齐且同源的完成日；前期推进与趋势资格沿用原模型 |
| 收敛描述 | 最近3个完成日相对推进段末5日的成交量中位数≤0.8、真实波幅中位数≤0.85；仅是观察证据 |
| 价格突破 | 收盘严格超过原平台上沿加缓冲；缓冲为0.1倍冻结ATR与正确价格单位下的最小变动单位两者较大值 |
| 量价突破 | 同时满足价格突破、较前日收盘上涨、收盘位于日波幅上部至少70%、当日成交量≥冻结参考量1.3倍；量能未知不确认 |
| 后续回测 | 量价确认之后5个交易日内，日低进入平台上沿±0.3ATR；突破当天不计回测 |
| 回测确认 | 触及后的另一个交易日、3日窗口内，收盘超过触及日高点加突破缓冲且不低于原上沿；此前回测日成交量中位数≤突破日0.8倍且≤冻结参考量。上行确认日允许放量，不混入缩量统计 |
| 回测受损/到期 | 新低较触及低点跌破0.1ATR即受损；超窗口未满足条件记到期。没有回测的直接上行不因此判失败 |
| 突破失效 | 收盘低于原上沿0.3ATR，或连续两天收盘低于原上沿，保留该次失败后允许新的突破尝试 |
| 周期关闭 | 完成日收盘低于原平台下沿0.3ATR，或失守同源MA20；关闭周期不复活，新周期必须有关闭之后的新推进段与整理 |
| 整理到期 | 没有有效突破尝试且整理超过12个完成交易日即到期 |
| 高量低推进 | 成交量≥参考量2倍、真实波幅≤0.5ATR、收盘推进≤0.2ATR时单列风险观察，不解释为主力行为 |

所有数值均为研究初值。这里的量价事实不能证明吸筹、派发、主力意图或完整的威科夫阶段。

## 验收证据

- 最终全套259项测试通过，其中新增32个结构场景，覆盖时间顺序、量能缺失、回测与失败、未来数据隔离、价格尺度、旧版本隔离、留档损坏、重复扫描等。记录见 [测试结果](unit_results.txt)。
- 修改前的实际报价和日线冻结对照覆盖3120只股票。除新增结构字段外，完整快照原字段逐项一致；新增20个可核验周期、回填事件数0。见 [冻结对照](frozen_comparison.json)。
- 服务已重新启动并核验已加载结构版本、快照、HTTP页面与日报的一致性；首次在线发布包含19个周期。线上名单与冻结名单时点不同，因此数量差异不作算法效果结论。服务随后完成下一轮自动扫描，保存的周期编号及平台/ATR/量能参考仍一致。见 [最终运行证据](final_evidence.json)。
- Edge实际页面检查了整理卡片及新化股份603867详情；新结构区块、原平台、固定ATR、当前报价尺度和首次不回填说明均显示。见 [详情截图](../../output/playwright/wyckoff-round1-detail.png)。
- 实际点击个股页“导出CSV”，下载3120行、217列，其中19行包含结构记录。全部代码与冻结全池一致；CSV行列对齐，结构周期编号、平台上下沿、ATR及量能参考与独立留档一致。导出文件为 [全池CSV](../../output/playwright/wyckoff-round1-all.csv)。

今日完成日线截至2026-09-30；截至本轮验收时尚没有上线之后的正式收盘结构事件。突破、回测和失效已通过场景验证，实际市场的收盘推进结果及收益需后续观察，不能据此称为“无漏洞”或收益已验证。
