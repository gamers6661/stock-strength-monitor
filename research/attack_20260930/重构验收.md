# 趋势进攻模型重构验收 · 2026-09-30

本轮目标是捕捉有实际推进能力的趋势股及整理后再次进攻。旧模型奖励低回撤、平滑路径和跑赢市场的天数，且A/B档受池内固定名额限制，这与用户的进攻风格不一致。本轮移除这些排名奖励，保留其原始信息作结构和风险解释。没有为任何证券代码写例外。

## 1. 现行模型

趋势资格保持完成日 MA5>MA10>MA20、MA20上行、收盘不低于MA10。核心数据仍要求最近25个应有交易日对齐且OHLCV有效；未对齐、恢复成交待日线对齐、停牌样本不会绕过核验。

三个评分周期为5日、10日、20日，权重50%、30%、20%。各周期分数为：

`周期分 = 60% × 绝对推进分 + 40% × 同口径收益分位`

`绝对推进分 = min(100, max(0, 实际收益 / 该周期满分收益 × 100))`

满分收益分别为5日8%、10日12%、20日20%。分位使用有效样本的并列平均分位。没有数据则不生成完整分，不以0分代替未知。绝对下跌不能凭相对抗跌成为进攻A档。量价、路径效率、回撤修复、题材、同行、资金不进入进攻分。

| 档位 | 条件 | 含义 |
|---|---|---|
| A | 趋势在线；进攻分≥65；5日和20日收益为正；5日≥5%、10日≥8%、20日≥12%至少一项 | 有实际推进幅度的进攻强势 |
| B | 趋势在线；进攻分≥45；20日收益为正；5日≥3%、10日≥5%、20日≥8%至少一项，或最近20日窗口出现过5日≥8%的推进段 | 进攻观察或强股整理 |
| C | 其余趋势在线股 | 结构在线，推进幅度或速度不足 |

档位不按池内前10%/前40%截断，也不补名额。全体分位和趋势池名次仍显示，帮助解释相对位置，但不再决定档位。

## 2. 盘中进攻与价格形态

盘中使用 `intraday.align_price_basis` 已核验并换算的同一份历史价格上下文。将当前价投影至5/10/20日收益，独立计算暂态进攻分和档位。完成日日线分、均线、收益、日期不因盘中上涨而被改写。

| 形态 | 可复查条件 |
|---|---|
| 趋势整理 | 最近三个完成日中出现实际收盘回落，每个完成日收盘各守各自MA10，当前仍守MA10 |
| 强股整理 | 上述价格整理且当前进攻档位为A/B |
| 反包修复 | 当日上涨、当前守MA10；前一完成日为阴线，当前价收复该阴线开盘价；没有收复20日高点时不冒称20日突破 |
| 整理突破 | 当前价超过报价日前20日最高价，且此前满足整理条件 |
| 20日新高突破 | 当前价超过报价日前20日最高价，此前未满足整理条件 |
| 整理再启动/短期突破 | 当前价超过此前3日最高价，按此前是否整理区分 |

所有突破均要求**现价**越过高点；恰好等于高点不算突破；日内高点曾触及、后来回落不算现价突破。整理只能根据已完成价格结构判断，不冒充缩量洗盘或资金承接。盘中反包和突破标为待收盘确认。

首页“进攻监测”条件：正常交易时段、有效报价、可比价格尺度、暂态A档、当日上涨≥3%或存在现价反包/突破、现价守住MA10且无严重转弱。严重下跌、明显冲高回落和失守结构不能进入当前候选。过热、触板未封、一字涨停或成交受限仍可被监测，但风险同时显示，不能由A档抵消。

竞价、午休、盘前、非交易日不产生新候选；历史参考明确标记。过期报价、口径未知、停牌和复牌待对齐不能产生新候选。报价新鲜度在页面打开后继续检查。

## 6. 本轮完成边界

本轮完成的是“趋势资格＋实际进攻排序＋价格再启动识别＋独立风险”的可运行初版。没有进行针对三只股票的参数寻优，没有声称得到最优权重或收益优势。5/10/20日速度存在相关性，样本分位会随有效覆盖变化；绝对推进占主要权重并公布参考样本数。下一轮应根据真实漏报、误报及冻结后的连续观察评估，而非看到一只股票不符合直觉就临时改阈值。
