# 市场强度模型规划

日期：2026-10-13。性质：负责人规划稿，尚未实施；数值是首轮试验参数，尚无收益最优性证据。

## 目标与输出

找到本项目覆盖范围内当前强势的板块、题材和个股，兼顾启动、推进、回踩整理。每个对象只输出两项主要评分：趋势强度 T、情绪强度 E；另列价格阶段、当日事件、风险和数据时间。两项评分不合成为总分。

默认关注 T≥65 或 E≥65 的对象。80 分以上称很强，65—79 分称强，45—64 分称一般，其余称弱。这是强弱识别，不代表收益概率。全量排行保留实际分数，不强行把排名靠前者称为强。

只需一轮有效数据即可更新结果。取消等待第二/第三次采样、固定等待 300/600 秒、待收盘才能列入等过程门槛。盘中结果随下一轮数据升降，显示统一的“截至时间”。

## 本轮核对到的事实

读取的本地快照生成时间为 2026-10-13 10:25:00。

- 当前报价池为主板，池规模 3,120，完整日线评分样本 3,026。
- 板块目录有 176 个行业、363 个题材；其中 450 个具有可用同花顺指数日线及当时的当前指数报价，89 个属于成员口径。
- 个股具有日线、当前价、开高低、当日涨幅、换手、成交额、涨停价等数据。现有盘中模型已计算市场相对涨幅、开盘后涨幅和日内位置。
- 现有日线进攻分为 5/10/20 日加权，权重 50/30/20，各周期 60%绝对推进、40%相对分位。
- 现有进攻档位受完整均线趋势资格约束，盘中重点候选又要求当日上涨/进攻事件。板块机会也有当前正向共振和重复采样门槛。
- 167 只历史持续强势个股中，当日下跌的有 122 只。这只能证明当天涨跌不能替代趋势判断，不能证明它们全部是健康回踩。

本规划沿用可覆盖的主板范围。同花顺指数可能包含非主板成员；不得把指数涨幅与主板成员涨幅混成同一序列，或把当前主板结果称为完整 A 股结果。

## 一、个股趋势强度

### 1. 分周期评估实际推进能力 A

R5、R10、R20 为统一价格口径下，截至当前有效报价的对应周期涨幅。完成日评价使用同样定义的完成日涨幅。盘中不修改原始日线。

先计算：

```
q5 = R5 / 8%
q10 = R10 / 12%
q20 = R20 / 20%
A5 = 100 × clip(q5, 0, 1)
A10 = 100 × clip(q10, 0, 1)
A20 = 100 × clip(q20, 0, 1)
```

这些尺度沿用已有进攻分的满分尺度，作为首轮对比基线。先分别完成三个周期的实际推进、相对领先和结构保持评估，最后选择最高分；不能先挑旧涨幅最大的周期，再只检查它的结构。

不再要求三个周期一起强，也不再对三个高度相关的涨幅反复加权。启动可能由 5 日贡献，持续推进可能由 10 日贡献，整理仍可能保留 20 日优势。至少一个有效周期表现出实际推进能力即可。

### 2. 同周期领先程度 S

S5、S10、S20 分别是对应周期涨幅在相同股票范围、相同交易时点的有效样本中所处的分位，取 0—100。

全市场相对地位是主依据，行业/题材内地位作为说明。同一市场涨幅从所有股票收益中减掉不会改变分位，不能把“市场超额”和相同收益分位当两项独立信息重复加分。

基础推进强度：

```
G_n = 60% × A_n + 40% × S_n，n为5、10、20
```

如果所有周期均下跌，A=0，G 最高只有 40；仅凭跌得少，不能进入强趋势档。

### 3. 分周期检查当前结构保持 K

每个周期检查对应支撑：5日用MA5，10日用MA10，20日用MA20。检查现价是否守住对应均线、对应均线是否非下降，以及距离该周期内最高完成日收盘的回撤。回撤使用已统一价格口径的前一完成日 ATR20；ATR 表示日常波动尺度，不给低波动额外奖励。

```
drawdown_n_atr = max(0, 最近n个完成日最高收盘 - 现价) / 前一完成日ATR20
```

首轮试验分段：

| 当前周期结构 | K_n |
|---|---:|
| 现价≥MA_n、MA_n非下降，该周期回撤≤1.5 ATR | 1.00 |
| 现价≥MA_n、MA_n非下降，1.5 ATR＜该周期回撤≤2.5 ATR | 0.85 |
| 跌破MA_n、MA_n下降，或该周期回撤＞2.5 ATR | 0.50 |

```
T_n = G_n × K_n
T_stock = max(T5,T10,T20)
主要强势周期 = 最终T最高的周期；并列时选择较长周期
```

K 只判断对应周期的趋势损伤。离均线太远、涨停、短期波动大等风险另列，不能因为风险高就否认其上涨力度。上述 ATR 分界需要在真实样本中比较，不宣称适用于所有股票。

不再把 MA5>MA10>MA20、R5 必须为正、今天必须上涨作为所有趋势强股的共同门槛。某周期结构破坏后，该周期评分最高50；所有周期均破坏时，趋势总分最高50，旧涨幅不会永久保留强趋势。

短期启动即使尚未恢复MA20，也可以由有效的5日/10日结构给出强趋势分，同时标注“短期启动，中期未恢复”。回踩失去短期支撑时，如果20日推进和结构仍强，可以由20日周期保留强趋势。某条均线失守不等于所有周期已经转弱。

## 二、个股情绪强度

用可观测的价格行为衡量交易热度和承接，不能据此声称知道投资者心理、封单资金或真实主力资金。

### 1. 当日进攻 D

对于具有正常有效涨跌幅限制的个股：

```
J = 100 × clip(当日涨幅 / 当日有效上涨幅度限制, 0, 1)
S0 = 当日涨幅在相同涨跌幅限制组中的分位
D = 60% × J + 40% × S0
```

当前主要是主板。后续扩展不同涨跌幅限制板别时必须分组，不能直接把 10% 与 20% 个股的原始涨幅横比。无正常涨跌幅限制的样本不能冒用普通限制，也不能把未知值当 0；单独展示原始涨幅，不参加这项常规分组评分。

### 2. 当日承接 H

```
L = 100 × clip((现价-日内最低价)/(日内最高价-日内最低价), 0, 1)
O = 100 × clip((现价/开盘价-1)/3%, 0, 1)
H = 70% × L + 30% × O
```

3% 是主板开盘后推升满分的研究初值；扩展板别时同步按涨跌幅限制缩放。

当前实际报价已到有效涨停价、有真实成交时，价格承接 H 按 100 处理，避免开盘即涨停、开高低相同的算术问题。这不代表封单质量、排队可成交性或全天封板。

其他高低价相同且非涨停的样本不猜测区间位置；对应完整情绪分不生成，趋势分独立保留。振幅很小时，日内位置意义有限，其贡献上限只有 H 部分，不单独构成强势资格。

```
E_stock = 70% × D + 30% × H
```

当天收益不为正时，J=0，E 最高只有 58；相对抗跌不能标成情绪强。高开后大幅回落会压低 H，即使账面涨幅较大也不会轻易得到高情绪分。

涨停、首板/连板、近 3 日活跃、昨日涨停今日表现保留为延续标签和同分排序信息。这些事实不继续叠成多个权重，缺少历史情绪信息也不阻止有效当日情绪分。封单额、封板时长、真实主动买入和可靠同时间段历史成交量不在本轮主因子中。

## 三、板块/题材趋势强度

本轮统一用已确认的主板成员计算核心强度，同花顺官方指数单独展示趋势参照。这样具有指数与仅有成员的题材能够在同一成员口径下评估。必须保留同花顺分类，详细行业与题材分别排名。

各周期计算同一组有效成员的等权区间收益。为避免单一龙头或异常报价抬高整体，成员至少 6 个时，去掉最高和最低各 max(1, floor(N×10%)) 个后等权平均，得到 Rb5、Rb10、Rb20。这是当前成员表现统计，不是官方指数，也不是历史真实成分回测。

按以下尺度分别评价周期：

```
qb5 = Rb5 / 5%
qb10 = Rb10 / 8%
qb20 = Rb20 / 12%
Ab_n = 100 × clip(qb_n, 0, 1)
Sb_n = 同周期成员收益在同类板块中的分位
Gb_n = 60% × Ab_n + 40% × Sb_n
B_n = 有效成员中同周期结构K_n≥0.85的比例，范围0—1
Kb_n = 0.5 + 0.5 × B_n
Tb_n = Gb_n × Kb_n
T_board = max(Tb5,Tb10,Tb20)
```

行业在行业中比较，题材在题材中比较。没有真实集体推进时 Ab 不高；仅有一个强股时，截尾处理和 B_n 会限制板块趋势强度。板块同样显示主要强势周期，不要求MA20先形成才能识别集体短期启动。

同花顺指数走势可以解释整体板块背景；它与主板成员分歧时，显示“指数/主板成员分歧”，不能用其中较强的一边替换核心评分，也不追加人工审批。

## 四、板块/题材情绪强度

```
Rb0 = 主板成员当日涨幅的同样截尾均值
Jb0 = 100 × clip(Rb0 / 2%, 0, 1)
Sb0 = Rb0 在同类板块中的当日分位
Db = 60% × Jb0 + 40% × Sb0
Bb = 有效成员中 E_stock≥65 的比例，转换为0—100
Hb = 有效成员 H 的中位数
E_board = 40% × Db + 35% × Bb + 25% × Hb
```

2% 是主板板块集体当日推升的满分研究初值。Bb 使用真实比例，不把 2 个强股与 20 个强股的裸数量跨板块比较。

上涨成员比例、涨停数量、昨日强股今日表现单列为原因，避免同一个涨幅在多项热度因子中重复加分。一个龙头的高分不直接代表整个题材高分；局部领涨的个股仍应在个股雷达中出现。

## 五、阶段、关系和页面

阶段回答价格运动发生到哪里，两项评分回答现在有多强。阶段使用当前有效行情和已有历史直接判断，不等待若干次采样。

| 阶段 | 要表达的事实 |
|---|---|
| 启动 | 近期原先不强，当前出现显著推升；短期趋势可以先强，中期结构未形成不阻挡展示 |
| 推进 | 当前趋势强，价格仍在推进或沿短线支撑运行 |
| 回踩整理 | 有强势背景，当前回吐/横盘，趋势优势和主要支撑仍保留；允许当日、5日收益为负 |
| 转弱 | 原有强势周期的结构破坏，且没有另一有效周期保留强度；短线若重新走强，标记启动/修复并说明中期背景 |

这里只冻结阶段的语义。执行前需要把边界样本统一成确定的判定顺序；不得沿用旧的“几次确认才改变阶段”流程。初版参考近3日运动、主要强势周期、对应均线及回撤损伤，不另建一套阶段总分。

“突破”“再启动”“反包”作为当日事件标签，不要求所有强势对象必须有事件。当前趋势评分已降到一般的历史强股，显示真实降温，不靠旧峰值永久保留强标签。

| T | E | 用户可读的含义 |
|---|---|---|
| 强 | 强 | 趋势与当日进攻同步，优先关注 |
| 强 | 一般/弱 | 趋势优势还在；结合阶段看推进、整理或回踩 |
| 一般/弱 | 强 | 当日热，可能启动或反弹；趋势尚弱如实显示 |
| 一般/弱 | 一般/弱 | 普通对象，不进入强势焦点名单 |

个股强度独立计算。板块强不能把弱股推成强股，板块暂时一般也不能阻挡独立强股。行业/题材作为共振说明；同一股票出现多个相近题材时去重，不累计题材分。

页面建议只保留：名称、趋势强度、情绪强度、阶段、事件、主要原因、最多两个主要风险。全页统一显示数据时间；详细数值在展开区域。可以切换趋势排序、情绪排序、阶段筛选。

默认强势焦点使用 T≥65 或 E≥65；全量排行仍可查看正在增强但尚未达到强档的对象。不要通过强制 Top N 制造“当前强势”名单。

## 六、保留必要的数据事实

报价时效、历史日期、复权/价格口径、确认成员、覆盖率仍在后端核对。它们保证分数对应真实数据，不是交易审批过程。

沿用当前板块正式统计至少6个有效成员、覆盖至少80%的边界，首轮不为当天名单放宽。小样本只展示原始成员事实和可用指数参照，不给等同大样本的整体结论。缺失数据不填0、不用历史报价冒充当前行情。

趋势数据不完整但当日报价完整，仍可算情绪分；当日情绪关键字段不完整，仍保留有依据的趋势参考并标明其时间。页面用一个覆盖摘要说明排除数，异常详情折叠，不增加待确认/待核验名单和按钮。

## 七、逻辑样例和验收

以下完全是假设样例，表中给出最终主导周期的分位和K，假设其他周期得分不高于该周期。用于检查公式语义，不是当前实盘股票、回测或收益证据。

| 假设样例 | R5 | R10 | R20 | 主导周期 | 该周期分位 | K | T结果 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 强势推进 | 8% | 12% | 20% | 20日 | 95 | 1 | 98.0 |
| 健康回踩 | -2% | 8% | 22% | 20日 | 95 | 0.85 | 83.3 |
| 慢涨但相对靠前 | 0.8% | 1.5% | 3% | 20日 | 95 | 1 | 47.0 |
| 曾涨很多、当前结构均破坏 | -8% | -3% | 18% | 20日 | 95 | 0.5 | 46.0 |
| 中期未恢复、短期启动仍强 | 6% | 2% | -8% | 5日 | 95 | 0.85 | 70.55 |
| 所有周期下跌、相对抗跌 | -0.5% | -1% | -2% | 20日 | 99 | 0.5 | 19.8 |

实际验收重点：

1. 低位急拉可进入情绪强势，未排成完整多头均线不能阻止展示；短期启动后情绪降温，只要对应短期趋势仍强，也不能被MA20门槛清除。
2. 健康回踩允许当日或5日下跌，仍保留强趋势；回吐过深/破坏支撑则降级。
3. 高开大幅回落的情绪分显著低于同涨幅、开盘后持续推升的对象。
4. 弱市中负收益相对靠前者不能仅因分位高被标成强。
5. 单一龙头拉高的板块不等同于成员共同走强；个股不会被板块门槛挡掉。
6. 旧报价、成员缺失和价格口径不明不会产生伪高分；也不阻断其他有充分数据的独立轴。
7. backend分数、列表、页面排序和显示时间一致；一轮有效更新即可进入/退出，没有隐藏采样等待。

执行时先保存原配置/源文件及一份冻结快照，在同一份输入上对照旧模型和新模型。只比较真实结果，不以当天必须选出若干只为标准。

日线结构可以用保存的历史回放检验；盘中进攻与承接必须使用已保存的真实盘中快照，不能把收盘高低价和最终收益倒灌为早盘已知信息。板块历史评估必须区分当时成员与当前成员的回溯统计。

## 八、取舍与未证明事项

周期择优会比旧加权模型更容易捕捉单一周期的快速进攻，也更容易受一次急拉影响；结构保持与独立情绪承接负责解释和限制这种偏差。若实际边界样本出现系统性误排，再调整该环节，不能提前堆入新门槛。

均线与ATR会滞后，且1.5/2.5 ATR不一定适合所有形态；分周期结构与情绪轴为启动提供入口，但两项分数仍需真实样本验证。短期反弹也可能成为真正的短期强趋势，必须注明主要周期和中期背景，不能把高分解释为长期反转。大涨幅饱和后可能同分，原始推进比例、另一轴强度、延续标签可用于同分排序。

这套规划评估已发生的强弱，不保证未来上涨或可成交。经典个股动量研究使用3—12个月周期，行业动量研究主要讨论6—12个月，不能据此宣称本项目5—20交易日参数已验证有效。

原始研究：

- [Jegadeesh与Titman（1993）](https://doi.org/10.1111/j.1540-6261.1993.tb04702.x)
- [Moskowitz与Grinblatt（1999）](https://www.aqr.com/insights/research/journal-article/do-industries-explain-momentum)
