# MA10持续跟踪与靠线回踩反弹验收

本轮已实施，运行版本为“强股整理观察6”。服务与实际页面已经加载新版。股票报价、历史完成日、盘中路径和正式收盘复核分别标注来源及时间。

## 1. 首次入榜与转强后跟踪分开

首次入榜仍需要整理前多头排列、实际进攻达到5日15%或10日20%、合格整理结构，以及当前多头排列和守住MA10。回踩至少2个完成交易日、横盘至少3个完成交易日。历史A档不豁免绝对进攻幅度。

已确认转强的股票退出整理主榜，进入原有展开区域的“转强后跟踪”。历史完成事件与当前进攻确认是两个字段：此前完成过整理，不代表当前仍在进攻。

| 本轮情况 | 当前显示与处理 |
| --- | --- |
| 失守MA5但守住MA10 | MA5回踩/短线降温，保留趋势跟踪，取消本轮进攻确认 |
| 跌回原平台突破位置以下 | 突破未站稳，历史完成事件保留 |
| 回踩修复后再次跌回修复位置以下 | 修复回撤，历史完成事件保留 |
| 当前MA5/MA10排列减弱但守住MA10 | 多头排列降温；首次入榜的严格资格不放宽 |
| 已转强后出现冲高回落等风险 | 风险观察，不继续显示本轮进攻确认 |
| 一次有效报价低于MA10 | MA10试破待确认，立即降级 |
| 两次不同时间连续有效报价低于各自MA10 | 盘中确认失守，退出跟踪 |
| 正式完成日收盘低于同口径MA10 | 收盘确认失守，退出跟踪；已有盘中退出时间保留 |
| 已退出后一次收复MA10 | MA10修复待确认 |
| 已退出后连续两次有效收复MA10 | 恢复修复观察，不能重新当作未启动整理股；MA5/平台/风险仍单独复核 |
| 报价、成交状态、价格口径或原整理历史不可核验 | 待核验，保留历史证据，不制造新转强或失守 |

每次采样使用其自身的MA10边界。重复、迟到、无效采样及超过15分钟的交易时间缺口不累积确认；午休由共用交易时钟扣除，隔夜重新累计连续次数。转强历史可跨日续接；只有确认后发生了新的进攻和新的合格整理结构，才允许识别为另一轮整理。

## 2. 新增回踩反弹状态

在合格强股整理中识别“下降靠近MA5/MA10/MA20，然后实质反弹”。三条均线均支持，选择靠线时距离最近的有效均线。

| 参数 | 本轮初值 |
| --- | --- |
| 靠线范围 | 上方不超过0.4 ATR；轻微下探不超过0.15 ATR |
| 下降靠线的最低幅度 | 0.25 ATR |
| 实质反弹幅度 | 从靠线低点同时达到0.5 ATR及2% |
| 盘中确认 | 靠线之后连续两次不同有效行情时间抬高，单次上跳不确认 |
| 完成日确认 | 已完成日的低点靠线及其后正式收盘反弹，明确标为完成日证据 |
| 完成日证据的新鲜度 | 最近3个完成交易日内的反弹确认 |
| 当前保持 | 当前仍高于靠线低点0.25 ATR并守住该参考均线 |

“回踩反弹”不替代平台突破、分歧修复或整理完成条件。仍有分歧时显示“回踩反弹·MA10 · 分歧待修复”等组合状态；已初步突破/初步转强时，原阶段优先显示。已离开初启动范围的股票继续按既定完成/待确认逻辑归类。

原始记录追加每次采样的ATR、MA5边界和MA20边界，既有列不移动。旧记录只有在原价格口径已核验时，才从其同一时点的暂态均线及价格反算边界；旧口径不可核验的记录不能参与新确认。

## 3. 日期和天数

榜单、详情及导出均提供整理开始日期、已经完成的整理交易日数和当日序号。未完成的当日不计入完成交易日数，周末及市场休市日不累加。初启动沿用原结构时，累计天数继续按交易日计算；已转强对象显示“转强前整理”，不继续把转强后的交易日算成尚在整理。

美盈森实际数据：9月23日开始整理，9月28日靠近MA10，9月29日正式收盘反弹；截至9月29日已整理4个完成交易日，9月30日为第5日。当前榜单显示“回踩反弹·MA10 · 分歧待修复”。生产规则没有针对股票名称或代码的白名单。

## 4. 联动修正

- 正式收盘复核从数据库读取正式日线，不使用被即时报价覆盖的日线副本，避免前复权历史与未复权报价混入同一个收盘均线窗口。
- 正式收盘的价格、MA10和价格口径单列显示；盘中原报价及原突破参考位保留原报价口径。
- 当前成交受限的报价不能贡献第二次整理完成确认；此前已确认的历史事件只保留为待核验参考。
- 收盘参考的详情及导出覆盖整理、转强跟踪、退出和待核验四种归类。
- 收盘确认不会覆盖已有盘中退出时间。协和电子的已核验盘中退出时间为10:34:38，正式收盘价39.61低于同源MA10的40.30；两项事实分别显示。
- 首次入榜资格、日线评分及盘中资金辅助分仍按原规则运行；本轮新增状态不反向给日线加分。
