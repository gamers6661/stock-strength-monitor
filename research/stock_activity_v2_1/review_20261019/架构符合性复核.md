# V2.1 架构符合性复核

复核日期：2026-10-19。以父目录《架构基线.md》为固定依据；本轮规则及评分版本为20261019.2。原架构文件保留定稿时状态，不用其“本轮仅固化文档”描述当前开发状态。

## 本轮发现并修正的偏差

| 架构要求 | 上一实现的偏差 | 修正及验收 |
| --- | --- | --- |
| 事件与身份分别管理，缺数据冻结 | 缺口直接将事件置为完成或过期 | 保存事件ID、既有证据和身份；记录观察暂停/恢复；不累计缺失时间；`test_gap_pauses_pending_event_and_rebuilds_before_confirmation` |
| 独立证据不能互相冒充 | 独立进攻写入时序领先标记 | 新增独立观察证据，不产生领先标记；两类核心角色同等准入；`test_independent_confirmation_never_claims_temporal_lead` |
| 只比较可比源时间 | 同一接收批次内，未进一步核对起终点源时间偏差 | 当前截面及收益区间按源时间±60秒核对覆盖；`test_same_receipt_batch_does_not_make_stale_sources_comparable` |
| 数据质量与行情状态分离 | 数据缺失覆盖结构状态为“数据待核验” | 保存最后结构状态，另存数据质量与实时可用性；`test_data_outage_freezes_last_structural_state` |
| 计算异常也保留已有身份 | 页面计算失败时返回空身份 | 从已保存状态恢复身份、事件和最后结构，只暂停排名；`test_projection_error_keeps_persisted_identity_without_ranking_it` |
| 身份与新事件分别确认 | 既往两次独立事件可以替代最新未确认事件参与再确认 | 独立核心最新事件也须通过承接及角色确认；`test_old_independent_events_cannot_confirm_a_new_pending_attack` |
| 新启动应及时出现 | 旧身份为失效时遮蔽后续新事件 | 新事件进入启动榜，旧身份失效记录仍保留；`test_new_startup_is_visible_after_an_old_identity_has_exited` |
| 恢复保留ID、锚点、证据时间 | 升规则版本会整体清空旧状态 | 仅对已知前版显式迁移，保留原证据时间并重建路径；`test_known_version_migration_preserves_identity_ids_anchors_and_times` |
| 停滞报价不等于连续有效观察 | 同一源时间重复接收时，可能继续展示实时身份 | 超过连续采样界限暂停实时榜；`test_unchanged_feed_cannot_keep_live_core_ranking_indefinitely` |
| 数据不足和无符合个股分别说明 | 空表后重复追加通用空榜解释 | 移除重复说明，详情显示恢复状态、观察与确认时间及独立证据 |

恢复期间，可核验完成日日线参考继续独立展示；它不参与盘中核心/启动排名，不能因缺少日内连续窗口而把所有日线参考一并清空。

## 其余架构核对

| 范围 | 实现与结论 |
| --- | --- |
| 数据准入 | 本页沪深主板、异常名称过滤、21完成日、2000万元成交额中位数及可比价格基准；没有修改共享股票池 |
| 有效进攻 | 实际推进超过固定噪声门槛，并通过扣除市场和排除自身行业的区间超额；高涨幅及高综合分不能补偿准入 |
| 三维判定 | 角色、结构状态、独立确认证据分别保存；未知结构为空，不用“日线参考”或“数据缺失”充当结构状态 |
| 双生命周期 | 事件正常结束不删除核心；结构/优势失效连续确认后退出；没有新事件不作为退出理由 |
| 双榜 | 已确认板块型及独立型核心同榜；新启动缺L或Q时保留候选但不生成完整分 |
| 评分 | L/H/E/Q统一版本与固定权重，R全榜关闭且为未检验；不逐股补50或重新归一权重；H不重复计多日涨幅 |
| 风险与可交易性 | 单独输出涨停成交约束及结构风险；不进入强度分和身份准入 |
| 证据充分度 | 分开保存采样、承接、角色及重复证据组成；暂停时采样部分为0，不据此判股转弱 |
| 时间与恢复 | 保存源时间、接收时间、触发区间、实际发现、逐项确认时间、最后有效采样；重建证据不回填成当时已知；重复输入不新增ID |
| 午休 | 跨午休实际重启与整段回放结果一致，承接只累计交易观察时间；专项测试覆盖11:30到13:04 |
| 筛选及输出 | 行业/题材原筛选语义保留；列表、详情、CSV来自同一个后端结果版本 |

## 证据与结论边界

- 专项测试、全量测试、冻结输入两版对照、实际HTTP及浏览器验收分别记录，不能以其中一种替代另一种。
- 冻结输入回放是当日可获得数据的工程验证。当前没有独立核心标注，不能据此宣称识别准确率、收益或权重已最优。
- 当前采样历史覆盖不足以完成长期分歧因子检验，R保持统一关闭。身份支持和退出使用已冻结规则；其效果仍须由跨市场时期的独立标注及样本外数据检验。
- 全站检查中此前已有两只股票缺少`session_context.structure_state`，与本页改动无关，保留原证据，不将其修复混入本轮。

本轮结论为：已补齐发现的架构实现偏差；功能符合性与实际选股有效性分别验收。具体执行结果见本目录`验收结果.md`及JSON/日志文件。
