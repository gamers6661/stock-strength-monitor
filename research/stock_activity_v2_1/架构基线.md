# 个股强度 V2.1 架构基线

- 定稿日期：2026-10-19。
- 状态：架构已冻结，作为后续开发与同输入对照验证的基线。
- 实现状态：本轮仅固化文档；不修改运行代码、行情数据、共享配置或评分参数。
- 冻结边界：架构、证据语义、生命周期、数据能力边界及验收目标。具体阈值与计算细节尚未确定，不得将候选权重或示例窗口视为已生效参数。

## 1. 目标与范围

识别当前市场中的主动强势个股，区分已确认核心、新启动、独立进攻与跟随上涨；及时识别已有核心转弱。强度、证据充分度、交易风险及可成交性分别输出。

仅围绕个股强度页面开发，保留板块、题材筛选按钮及原有筛选语义，不改变其他页面的股票池、评分、分类、行情与展示结果。

第一阶段使用现有日线和120秒采样。共享沪深主板股票池配置保持不变，个股页面使用独立候选池配置；具体候选范围在参数规范中确定，不通过修改共享配置扩展范围。

不提供缺乏数据支持的逐笔主动买盘评分；不将采样路径表述成完整分钟行情。第一版不启用市场状态自动改权重或自动寻优。

## 2. 固定系统结构

数据准入与历史恢复
→ 有效价格进攻检测
→ 进攻角色、当前状态、确认证据分别判定
→ 核心身份有效性与榜单准入
→ 核心前排榜、主动启动榜
→ 统一可用因子评分及证据置信度
→ 持续观察与独立退出判断。

其中：

- 数据准入处理股票范围、交易制度、口径可靠性、流动性、异常样本及采样完整性。
- 有效价格进攻要求实际价格推进、超额优势与噪声过滤。
- 身份和榜单资格不能由综合分补偿获得，也不能仅由某个L分数阈值决定。
- 身份有效性与本次进攻事件的存续分别管理。
- 排名和可交易性分别计算，一字涨停等成交限制不直接否定真实强度。

## 3. 三个互不替代的维度

| 维度 | 固定语义 | 说明 |
| --- | --- | --- |
| 进攻角色 | 板块先行、独立进攻、跟随进攻、时序不明 | 根据有效进攻事件与可比源时间区间判断 |
| 当前状态 | 推进、领先保持、强势整理、转弱、失效 | 描述当前结构，与是否有新事件分别判断 |
| 确认证据 | 有效进攻、承接、时序领先、同行扩散、跨事件重复 | 独立保存各项是否成立、成立时间及依据 |

确认证据不是必须逐级通过的单一等级。承接、时序领先和跨事件重复等可以独立成立；底层保留原始证据标记，再按固定规则计算对外展示的确认阶段。不得用单一阶段字段替代证据记录。

独立进攻不是低一级核心。持续保持领先优势、市场关注度并出现多次有效进攻的个股，可以获得独立型核心身份；无同行扩散时，不描述为其带动板块。

## 4. 两套生命周期

| 项目 | 进攻事件 | 核心身份 |
| --- | --- | --- |
| 创建依据 | 新的价格进攻触发 | 领先与核心地位得到确认 |
| 关键锚点 | 启动区间、突破价格 | 重要价格结构、优势区间、核心证据 |
| 正常结束 | 本次进攻完成或过期 | 不因事件正常结束而退出 |
| 失效依据 | 当次信号失败 | 已有优势与结构出现明确失效证据 |
| 数据中断 | 暂停事件更新 | 保留最后确认身份并标记数据过期 |

事件完成、事件过期、事件失败与核心身份退出分别记录，不能互相隐式替代。一次承接失败首先影响当次事件；核心身份是否退出，仍须满足独立的身份失效规则。

例：10:00产生进攻，11:00事件结束，14:00继续有效横盘，应记录为事件已结束、既有角色保留、核心身份仍有效、当前状态为强势整理。

强势整理期间仍须有可观测证据支持相对前排地位和关键结构；不能凭过去一次事件无限保留有效核心。持续支持条件及退出阈值在参数规范中预先冻结。

## 5. 触发、确认与退出

### 5.1 初步触发

设价格推进为ΔP，最小有效波动门槛为θ，市场及板块调整后的收益为ER。初步触发至少满足：

ΔP > 0，ΔP > θ，ER > 0。

θ须同时考虑最小有效价格变动、正常波动噪声及可确认的报价误差，不能只使用历史分位数。ER的基准、计算方式和有效窗口须在参数规范中确定。

触发即进入启动待确认区域；后续有效采样验证承接与持续性，不将等待两个采样周期作为首次展示的前提。快速失去突破成果的事件判为失败，不提前升级为已确认的有效进攻。

### 5.2 核心退出

| 观察结果 | 处理原则 |
| --- | --- |
| 关键价格结构持续失守 | 转弱；达到独立退出确认条件后退出 |
| 对市场或板块的领先优势显著丧失 | 重新评估核心身份 |
| 连续有效采样确认承接失败 | 判定本次进攻失败；身份退出另行判断 |
| 没有新的启动事件 | 不据此退出 |
| 正常强势横盘且结构、优势保持 | 保留身份 |
| 数据缺失或采样中断 | 冻结判断，不推定转弱 |

进入与退出采用不同门槛及必要滞后区间，退出需要连续有效证据。具体连续时长、有效采样条件、结构锚点和优势保持标准尚待规范。

## 6. 120秒采样的时间与判断边界

至少保存以下时间信息，并与事件、证据及身份关联：

| 字段 | 语义 |
| --- | --- |
| source_timestamp | 行情源记录时间 |
| received_at | 系统接收时间 |
| trigger_interval | 真实启动可能发生的时间区间 |
| detected_at | 系统首次实际发现时间 |
| confirmed_at | 相应证据实际得到确认的时间；各类证据分别保存 |
| last_valid_sample_at | 最后一次有效采样时间 |

先后判断只使用有效、可比的行情源时间区间，不能按请求完成或系统接收顺序判定。

- A、B同为10:02—10:04，C为10:08—10:10：可以确认A、B的可观察启动早于C，不能确认A早于B。
- 缺失采样不能作为跟随证据，也不能跨缺口拼接虚假的连续进攻。
- 板块基准排除个股自身；主题归属与比较规则须在比较前固定，不能启动后挑选最有利的板块。
- 同行扩散只能在实际得到证据之后增强确认；不得回写早期判断或声称因果带动。
- 重复报价、采样缺失、午间休市及集合竞价等边界须按实际交易时段处理。
- 累计成交额、成交量计算VWAP前须校验单位与价格区间合理性；只能据现有采样描述保持情况。

## 7. 榜单归属

### 核心前排榜

已确认且当前有效的核心，包括板块先行核心及独立型核心。事件结束不直接移出；已有核心可以处于推进、领先保持或强势整理。

### 主动启动榜

已经触发进攻、身份正在形成的股票。历史H较低不阻止进入；Q等证据尚未确认的股票进入待确认区域，显示当前可观测值，不展示伪装成正式结果的完整综合分。

两榜均须区分数据可用性与股票强弱。长时间数据中断时可以暂停实时排名或撤出实时榜，但保留历史身份及最后确认时间。

跟随进攻不能仅凭高涨幅或高综合分升级为板块发动核心。其后出现新的独立有效先行事件时，依据新证据重新判断。

## 8. 统一评分版本

| 因子 | 固定职责 |
| --- | --- |
| L 主动领先 | 可信时序及相对先后证据；时序不明不得伪装成确认领先 |
| H 核心身份 | 核心身份、历史领先事件和相对成交关注；不重复奖励多日收益排名，历史事件不重复计入当前事件 |
| E 超额强度 | 使用去重后的收益区间，衡量扣除共同上涨后的价格优势 |
| Q 量价承接 | 有效进攻之后的成果保持；承接确认窗口结束才形成正式结果 |
| R 分歧韧性 | 真实分歧中的保持与修复；可比历史样本足够才统一计分 |

沿用讨论中的候选权重，仅用于后续规范与验证，尚未生效：

| 榜单 | L | H | E | Q | R |
| --- | --- | --- | --- | --- | --- |
| 核心前排 | 30% | 20% | 20% | 20% | 10% |
| 主动启动 | 40% | 10% | 20% | 20% | 10% |

启用的因子、权重、标准化方式及完整分条件属于统一评分版本，不由每只股票临时决定。R覆盖不足时，在对应榜单版本中统一关闭并展示证据标签，不逐股补50分、不逐股重分配权重。关闭因子后的统一计分口径须在验证之前另行冻结。

强度分与证据置信度分开输出，置信度的具体算法及展示语义尚待规范，不能将其直接解释成未来上涨概率。

## 9. 冷启动、中断及恢复

| 场景 | 必须行为 |
| --- | --- |
| 第一次运行 | 用可核验日线、历史采样建立参考身份；不能宣称分钟级领先已确认 |
| 正常盘中重启 | 恢复事件ID、锚点、三维信息及确认时间，不重复生成同一事件 |
| 短暂采样中断 | 保留最后确认结果、标记数据过期，不推断转弱 |
| 长时间中断 | 暂停实时确认与排名更新；必要时撤出实时榜，保留历史身份 |
| 恢复采样 | 重新建立足够连续的有效窗口，不跨缺口拼接进攻 |
| 午间休市 | 按交易时段处理，不当作异常缺口 |
| 没有合格股票 | 显示“暂无符合条件的个股” |
| 数据不足 | 显示“当前数据不足以完成判断” |

日线参考身份和盘中确认身份明确区分。数据可信度下降不能自动转换成股票转弱。

## 10. 下一阶段必须预先确定的参数规范

以下为待定项，不是已经批准的数值参数：

| 类别 | 待确定内容 |
| --- | --- |
| 候选池与数据 | 个股页面候选范围、交易制度分组、流动性与异常样本规则、价格及成交单位口径 |
| 有效进攻 | 检测窗口、ΔP定义、θ的噪声与报价误差口径、ER基准及计算方式 |
| 时序与角色 | 启动区间构造、可比源时间、同行启动与扩散标准、独立及跟随判定 |
| 承接与事件 | Q确认窗口、突破锚点、事件完成/失败/过期、重复事件与跨事件划分 |
| 核心身份 | 板块型/独立型准入、前排地位及关注度要求、整理存续支持条件 |
| 转弱与退出 | 结构失效、优势丧失、连续证据、进入退出滞后区间 |
| 采样及恢复 | 可接受缺口、重复与无效报价、连续窗口、短长中断界限、恢复条件 |
| 统一评分 | 因子启用门槛、固定权重、标准化、缺失处理、R关闭后的统一分值口径 |
| 展示与证据 | 确认阶段映射、置信度语义、实时榜可用性、状态恢复与版本兼容规则 |

参数与规则版本须在独立验证前确定，不根据当日名单或反复回测结果临时放宽以制造合格个股。数据不支持的指标不得以代理值冒充实测结果。

## 11. 固定验收场景

| 场景 | 预期结果 |
| --- | --- |
| 新启动股票率先主动突破、历史H低 | 及时进入启动待确认；不得仅因H低拒绝 |
| 板块已普涨、个股随后拉升 | 不误判为板块发动核心 |
| 独立强势、多次有效进攻、无同行扩散 | 可以确认为独立型核心 |
| 老核心没有新进攻，但结构与优势仍在 | 保留核心身份 |
| 老核心持续丧失优势并跌破有效结构 | 按连续证据及时转弱及退出 |
| 两股启动区间重叠 | 时序不明，不强制判断谁先发动 |
| 中间漏掉一次采样 | 不拼接，不判断缺失期间的先后 |
| 进攻后立即回落 | 事件失败，不提前确认承接 |
| 分歧事件缺失 | R未检验，不补分 |
| 午间重新启动系统 | 状态恢复，不重复触发 |
| 整个采样服务中断 | 标记数据不可用，不误判退潮 |
| 没有新启动，但已有有效核心 | 核心榜正常保留，启动榜可以为空 |

上述“新启动”指新进攻事件，不隐含放宽新上市股票的数据及交易制度准入要求。

验收保留每次判断的触发证据、事件时间、身份变化原因及参数版本；同一输入可重复回放。合成边界测试与真实行情回放分开报告，不能将构造样本的预设标签当成实盘统计结论。

## 12. 实现与对照验证顺序

1. 预先冻结首轮参数规范与统一评分口径，核验真实可回放输入覆盖。
2. 实现事件记录、身份持久化与恢复机制。
3. 实现角色、当前状态和独立确认证据，再实现身份有效性及双榜准入。
4. 接入统一可用因子评分、证据置信度及独立交易风险展示。
5. 在同一批真实输入上，与普通涨幅榜、多周期RS榜、板块内收益排名对照。

主要比较领先识别、新启动发现、核心保持、退潮剔除和误报情况。独立标注或独立事件标签与模型状态分开，不能使用模型自己的输出作为正确答案。

收益与交易可执行性作为另一组评价，不以人工排序或功能测试通过宣称模型有效。验证需同时证明个股页面以外的结果保持不变，板块筛选仍可使用。

架构层面停止扩展；后续工作围绕本基线补齐参数规范、实现和证据，不继续堆叠因子或启动自动权重寻优。
