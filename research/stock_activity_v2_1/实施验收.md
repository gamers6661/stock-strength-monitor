# 个股强度 V2.1 首轮实施与验收

日期：2026-10-19。规则版本：`个股主动强度V2.1-20261019.1`。评分版本：`LHEQ-R关闭-20261019.1`。运行实现指纹：`fcb0537c675c2316`。

## 已部署的行为

- 个股页改为核心前排、主动启动、日线强势参考和观察范围；保留原板块、题材筛选，筛选不重新计分。
- 实际价格推进、市场与排除自身的行业超额、噪声门槛共同触发事件；待确认及时展示，缺少正式因子不凑完整分。
- 角色、结构状态、各项确认证据分别保存。承接、时序、扩散、重复事件独立成立，不压缩成不可逆的单一级别。
- 进攻事件与核心身份分别存续；正常结束、整理或没有新事件不直接撤销核心。连续结构/优势失效才退出，退出后不能复用已消费的旧事件自动重新入榜。
- 支持独立型核心及跨交易日的独立重复进攻；单一连续拉升不能被切成多个独立事件。
- 日线历史强势也检查当前结构及相对优势，明显转弱股票移到观察，不由旧涨幅掩盖当前失效。
- 统一启用L/H/E/Q，R统一关闭；交易约束和风险值不参与强度计分。参数仍属于待实证验证的固定初始规则。
- 保存源时间、接收时间、发现时间和各项实际确认时间。历史采样重建明确留标记，不回写成当时已被系统发现；保存状态的知识时间晚于回放截止时间时不复用。
- 数据中断保留身份、冻结判断，恢复后重建连续窗口。隔夜不拼接日内路径，午休不计缺口；下个交易日采样可在全站扫描完成前更新本页。

## 文件与发布路径

| 文件 | 职责 |
| --- | --- |
| `stock_activity_rules.py` | 页面独立候选范围、固定参数及统一评分版本 |
| `stock_activity_engine.py` | 纯计算事件、确认证据、身份、准入及因子结果 |
| `stock_activity.py` | 只读日线、报价口径、历史恢复、本页状态日志及原子发布 |
| `stock_activity_sampler.py` | 原120秒独立采样完成后发布本页结果，并记录计算时间、源时间与发布时数据年龄 |
| `stock_activity_ui.js` | 双榜、参考列表、详情、筛选与同版CSV；仅包装个股页入口 |
| `serve.py` | 增加只读 `/__stock_activity` 接口；其他路由行为不变 |

本页独立状态与日志在 `cache/stock_activity_v21/`，不迁移V1分数为V2.1核心身份。独立发布使用本页跨进程锁，不占用全站扫描锁。浏览器在个股页轮询本页结果，不等待全站发布；列表、详情和CSV读取同一强度结果版本。

已有页面需要完整刷新一次以加载新版脚本。旧客户端仅热更新DATA不能加载新的JavaScript函数；验收已在完整刷新后完成。
