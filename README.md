## 看什么

1. **日线趋势**：上述完成日均线排列和收盘条件同时成立才算日线趋势在线。排列成立但收盘跌破 MA10，标记为日线失守。它用于历史候选，不代表盘中仍强。
2. **回踩 MA10**：历史形态和当前状态分开。当前回踩候选只在正常交易时段、逐股报价仍有效时计算，还要守住盘中 MA10、通过严重风险与位置过热检查，且没有明显成交限制；价格下跌后不再过热不能单独重新入选。
3. **价格判断**：资金流参考与历史资金补采已停用，现行评分、排序和筛选不使用资金流入流出。
4. **风险约束**：跌幅、盘中失守 MA10/MA20、冲高回落、触板未封和报价过期各自标记。报价不可判断时不判转弱、不记零分。风险阈值集中在配置中并标为研究初值。
5. **情绪轴**：同一批有成交报价同时统计涨跌、涨停、触板未封、昨日涨停股当日反馈；个股区分热度和承接。主榜外的活跃股放在独立观察区，趋势标为未核验。
6. **行业助攻**：趋势看剔除自身后的同行在线比例、近两次广度变化、剔除最强两只后的广度和同行短期超额；情绪看剔除自身后的同行活跃比例，以及前后两个交易日的涨停参与是否扩大。前者使用主板已对齐完成日线样本，后者使用当日有成交报价的主板样本；只展示共同表现，不声称某股带动板块。
7. **题材助攻**：逐项计算股票所属的同花顺概念关系，页面和日报分别显示各题材剔除本股后的三日趋势参与、五日相对表现和当日情绪扩散；F10缺失时标待核对。重叠题材不累计奖励，题材不进入个股自身强度，也不代表上涨归因。

日线进攻以 **5日50%／10日30%／20日20%** 排序。各周期为60%绝对推进分＋40%同口径收益分位；绝对推进满分对应5日8%、10日12%、20日20%，负收益该部分为0。低波动、回撤小、跑赢市场的天数不加分，量价与回撤保留作解释。

A档要求完成日趋势在线、进攻分≥65、5日和20日上涨，且5日≥5%或10日≥8%或20日≥12%。B档要求进攻分≥45、20日上涨，且达到5日≥3%或10日≥5%或20日≥8%，或最近20日出现过5日≥8%的推进段；其余结构在线为C。各档不限制名额。初值未作样本外收益验证。

首页“进攻监测”使用共用核验结果投影当日5/10/20日涨幅，独立生成暂态进攻分和档位。暂态A且当日涨幅≥3%或存在现价反包/突破、并守住MA10及无严重转弱才入监测；过热、触板未封、封板成交限制仍显示，不抵消进攻强度。形态区分强股整理、反包修复、整理突破、20日新高突破与短期突破；盘中成立须待收盘确认。过期报价、口径未知、恢复成交待日线对齐均不产生新候选。

新日线历史保存在 `cache/stock_strength_daily/v6/`，新收盘名单保存在 `cache/close_strong_attack_v6/`，旧评分与旧分位不拼接。旧四因子研究脚本固定使用其冻结的v5模型。

“增强／维持／衰减／修复”归在**日线近期变化**，与盘中变化分开。日线强度分位的变化只使用真实保存的完成日历史，不回填旧数据。

资金分两层展示：当日资金通过全市场批量来源核验并显示来源、覆盖和时间；东财不可用时，新浪只提供当日超大单净额，口径单独标注。个股完整3/5/10日结论仍受多日逐股核验限制：每个完成交易日最多核验60只候选，优先最近回踩股再按20日涨幅补足，只有完整日期覆盖才显示周期结论，其余为未知。逐股日级结果缓存在 `cache/fund_daily/YYYY-MM-DD.json`，同日刷新复用；接口连续失败时本轮停止重试。不同来源和口径不拼接成连续曲线。

收盘前只用前一交易日完成 K 线判定日线趋势和回踩；报价时间单列。核心评分要求最近25根完成日线日期对齐、OHLC及成交量有效：四项强度最多使用21根，MA20五日前参考需要25根。更早的缺口不再排除核心评分；60日收益、MA60与60日位置须另有61根对齐有效日线，否则为未知，不缩短窗口冒充60日。最近21根可核验而不足25根的样本继续显示“趋势可核验、强度待评分”，缺失日期和异常日期记录在覆盖目录。

## 个股列表与观察标签

个股页只有一张完整样本表：展示当前覆盖的股票，包括待评分、无成交和报价异常样本。默认把有效评分排在前面，其余明确标注。每只股票只显示一个主要观察标签：有效报价下的大跌、接近跌停或明显冲高回落优先标为风险观察，其余按统一盘中状态显示当前强势、初步转强、盘中修复、活跃观察、相对抗跌、今日转弱或暂态趋势待观察；无有效盘中状态时显示日线趋势、待评分；其余标为普通样本。风险、报价时间和具体趋势状态仍在独立列展示，标签不会改写历史评分。

“当前强势”必须同时满足：历史强势基础、上一完成日日线趋势、当前暂态趋势、当日涨幅为正、跑赢主板等权基准、现价不低于开盘价、三项盘中分完整、正常交易时段报价有效，且当前风险约束通过。盘中分高于50不能代替这些方向条件。触板未封进入分歧观察，不进入当前强势或低风险回踩；位置偏热仍保留强势事实，但不进入当前回踩候选。详情列出未通过的资格项。

“初步转强，待收盘确认”要求上一完成日趋势明确未成立、当前暂态趋势成立、当日上涨、跑赢主板、不低于开盘价、三项盘中分完整且至少70分，并通过当前强势同口径的风险约束。历史趋势未知不视为未成立。高分但不满足强势或转强资格，仅标“活跃观察”；开盘后回升但仍下跌或落后主板，标“盘中修复”，严重风险与触板未封优先单列。四类资格互斥，均不改变日线强度与盘中分。首页仍只列当前强势与初步转强，活跃和修复在现有个股列表及详情中查看。首页、列表、详情使用同一个后端观察状态，位置偏热继续单列为风险。

首次打开没有隐含趋势筛选。行业、题材等筛选只缩小完整样本范围；“清除筛选”恢复完整列表。搜索命中但不满足用户筛选条件的股票单独列出。总览、个股页和 CSV 共用样本范围及排序。

## 盘中观察

盘中观察分包含三项：当日相对主板等权基准表现的横截面分位、现价相对开盘价收益的横截面分位、现价在日内高低区间的位置。三项齐全时等权平均；缺一项就不生成完整盘中分，也不重新分配权重。高低价相同时日内位置“不适用”。一字板显示封板状态／成交受限并退出普通三项排序。减去相同市场基准后再做分位与直接按当日涨幅排序相同，主要新增信息来自开盘后表现和日内位置。主榜同时显示当日涨幅与主板超额。盘中分不折算全天成交量，资金、题材数量和所属最强概念不计入盘中分。

当前强势以独立资格判断，不以三项平均分代替方向判断。“相对抗跌”“盘中修复”“初步转强，待收盘确认”“活跃观察”“今日转弱”和“分歧观察”描述实际表现；历史回踩形态保留在详情中，当前资格另看现价、风险、过热和成交限制。

报价日为 D 时，固定参考均线只用 D 日之前的完成交易日。暂态 MA5/10/20 分别使用最近4/9/19个完成日收盘价加当前价；暂态 MA20 上行对照 D-1 完成日 MA20。收盘后日线源若已更新到 D，也不改变这条暂态基准。若行情昨收与最新完成日收盘口径相差超过配置的5%，暂停该股均线判断并标出差异。

收复／失守只比较两轮各自的价格与该轮 MA10：上轮价格低于上轮 MA10、本轮价格不低于本轮 MA10才算观察到收复；失守反之。两轮报价都须有效，且本轮逐股报价时间严格晚于上轮。首轮只显示当前位置；收复 MA10 不代表完整趋势恢复。页面分别显示“扫描观察到收复”和下一轮仍保持的“收复保持”。收盘时固定保存最后一轮有效盘中判断与正式收盘结果，后续扫描不覆盖。

正常盘中扫描会核验报价日期和时段、逐股报价时间、同批次偏差、现价与开盘价是否落在日内高低区间、当日是否有成交，以及报价昨收与最新完成日收盘的可比性。集合竞价独立更新报价观察：只要求当日竞价时段内的有效时间和现价，不要求成交额，也不生成正常盘中评分或新的均线结论。报价过期或异常时当前状态未知，不生成新结论；旧值显示最后有效时间并退出当前候选。页面打开后也按实际报价时间和当前交易阶段重新检查当前候选；午间保留上午最后有效状态，收盘后展示正式确认及盘中对照，非交易日展示最近交易日结果。页面新鲜度依据实际逐股报价时间判断，文件生成时间不代表行情变新。

交易日另在 **09:15、09:20、09:25、09:30、11:30、13:00 和 15:00** 启动阶段报价获取；行情源尚未更新时短时重试，实际抓取时间和源报价时间分别记录。09:15 起展示逐股竞价报价，09:25 保存竞价结束参考价；09:25—09:30 标注竞价已结束，不再把后续时间戳当作竞价价。竞价阶段不要求成交额，也不生成正常盘中评分。09:30 正式开盘后，逐股拿到有效正式报价才切换，等待期间明确标注竞价参考价，竞价价不参与正常盘中候选。11:30—13:00 展示上午收市价格；13:00 开盘后，逐股拿到有效午后报价才切换，等待期间继续显示明确标注的 11:30 参考价。缺少上午收市价格的股票标明更早的有效报价。收盘后先展示 15:00 报价；正式完成日线到齐后，价格和强势主榜以当日完成日线为准。阶段参考价各自留存在当日快照中，常规五分钟扫描不会覆盖它们。

真实扫描记录保存模型版本、规则版本、逐股报价时间、比较样本、三项分完整度和候选身份至 `cache/intraday_history/`。评分变化明确表示相对评分变化；若比较样本改变会提示分位解释受样本影响，不称为资金增强或上涨加速。研究报告按交易日分别比较盘中分、直接当日涨幅和原日线排序在下一扫描、较长盘中窗口及收盘时的后续价格表现，并记录失守率、冲高回落率和候选名单变化。重复扫描不作为独立交易样本；结果不称为可实现交易收益。模型或规则改版后分版本统计，旧分与新分不直接对照。样本不足时不调权重。

次日首次刷新会检查历史库是否缺少上一交易日完成 K 线；若缺失，会先批量补齐，再计算趋势。补齐覆盖不足或完成日线日期回退时保留上一份快照。

## 使用

- 默认双击 `打开看板.bat`，通过本地服务打开持续更新的看板。直接打开 [dashboard.html](dashboard.html) 只会看到静态快照，不会接收后台发布；页面显示数据生成、扫描完成、日线判断日和逐股报价时间。“刷新数据”会请求服务扫描，发布成功后页面自动载入新版本。
- `python daily.py --quiet`：更新行情、看板和日报。
- 同花顺目录与成员名单每7天检查一次，在盘后更新；未完整通过时恢复旧名单。常规五分钟扫描只更新行情及判断。主动更新分类可运行 `python refresh_classification.py`，下一轮行情扫描使用新成员。个股 F10 归属核对不在每日扫描中自动重抓；没有本地记录时显示待核对。
- 概念浏览合并已保存的同花顺个股 F10 和概念详情成员，保留两路来源差异；日线因子和原有评分仍采用 F10 优先口径。点击概念进入“全部样本”查看当前覆盖的所有成员，包括待评分股票；概念人数表示当前覆盖成员，不表示强势股或全市场完整成员数。筛选面板的概念人数也按同一成员名单计算。
- 09:15—09:25 集合竞价定时或手动刷新会获取当日有效报价，成交额为零不妨碍展示；完成日线评分与收盘名单沿用上一份快照，竞价报价单独标注。09:25 的竞价结束报价按实际源时间保存，09:25—09:30 只展示竞价结束参考。09:30 后恢复正常盘中报价和成交有效性检查；正式报价未就绪时先显示竞价参考价。竞价时间或价格无效时保留上一份结果。
- `python rebuild_strength.py`：只允许同一完成日的本地重建，沿用原报价时间并重建收盘主榜；日线日期变化时拒绝沿用旧派生结果，请运行正常收盘更新。
- `python -m unittest test_close_monitor test_strength test_emotion test_stock_strength test_intraday test_intraday_volume test_coverage test_radar_strength test_theme_assist test_classification -v`、`python check_dashboard.py`、`python smoke_test.py`、`python check_live_service.py` 是原有规则的验证入口。MA5／MA10／MA20 趋势观察按目标线独立计算，功能正确性与评分是否带来额外区分能力分开统计。

本地服务启动时会核对已加载的日线趋势、日线强度、盘中模型版本和快照字段；不一致时先更新快照，等待期间页面显示初始化状态，不会展示旧榜单。每轮后台扫描同时发布看板与 `snapshot_report.md`。`/__status` 提供当前服务进程、三个模型版本、扫描状态和已发布快照时间；修改计算代码后仍须重新启动服务，不能只重建静态页面。

个股页默认展示全部样本，股票名称旁显示主要观察标签；主表收成股票、今日、日线分、盘中分、关键状态、行业／概念六列，复杂的相对评分变化、风险原因和趋势依据移到个股详情。A/B/C 按日线基础强度分层，只代表日线关注级别。详情展示现行价格评分、日线确认与暂态均线、报价有效性与风险、逐股报价时间、行业/题材及可核验来源；CSV 与总览采用同一筛选条件和排序。角色中的“20日领涨”表示当前覆盖同行的20日涨幅名次。

情绪状态与助攻阈值只是首版描述标签，尚未据此收紧趋势池。行业自身的持续扩散、初步扩散或收缩，与个股相对同行的领先或落后分开显示；“核心独强”必须有强度、绝对上涨和同行超额共同支持。涨停使用报价接近涨停价的近似判定，盘中标为暂态；现有日线与单次报价无法判定封板时刻、开板次数、个股带动板块的先后关系。行业比较只覆盖当前主板有效日线样本，题材助攻只覆盖主榜有效成员，不能代表完整题材。资金参考已停用。

## 2026-09-29 资格统一与冻结研究
